# FEM multi-trajectory contract gate

## Five pre-launch questions

1. **Mechanism question:** Which currently available FEM packages support road-like leave-one-trajectory-out, and which support only a controlled shared-geometry leave-one-combination-out gate?
2. **Claim change:** The hard/soft x 5/8-step factorial may unlock a scoped numerical LOCO study. Road-like training remains blocked until independent producer handoffs pass. Neither outcome changes FEM/PIDL mechanism claims.
3. **Cheaper diagnostic:** Yes. Audit existing packages, metadata, field shards, hashes, and split identities before any training. This task is that diagnostic.
4. **Minimal output asset:** A versioned bundle schema, source-backed manifests, validator report, locked split skeleton, registry, and decision note.
5. **Registry path:** This package is the readiness endpoint. Independent producer handoffs must enter its registry and pass the same validator before the split lock can be regenerated.
