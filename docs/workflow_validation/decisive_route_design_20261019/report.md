# First-principles route design and decisive validation

Date: 2026-10-19. Owner: research-workflow skills. Planning tests only; no
scientific experiment, producer run or new data access was performed here.

## Correction

The prior core defaulted to a smallest test, the repair guide preferred one
intervention, and Road/Deep Research invocation prompts repeated smallest-test
language. Together they could turn an important route choice into a serial
chain of narrow component checks.

The new core starts material route adjustments from goal, mechanism/information,
constraints, measured bottleneck and competing explanations. A concrete coherent
redesign is allowed; its actual intervention, expected causal signature and
comparison must be stated. Validation coverage follows what can change the
research decision, not minimum runtime or minimum number of modified parameters.

Small checks remain useful for a real unresolved blocker. Already resolved
plumbing/feasibility is reused, not retested automatically. Related checks can
be combined into one decisive comparison. Component progress is preserved, but
does not replace consequential progress on the main goal. Larger runs alone are
not a breakthrough design either.

The four installed skills resolve to these tracked sources. Existing scientific
protocols, past results, holdouts, execution authority and GPU budgets are
unchanged. A simple primary criterion remains appropriate; that does not imply
a scientifically underpowered or unrepresentative experiment.

## Independent forward test

Evaluator: `/root/decisive_route_forward_test`, fresh context; raw inputs in
`scenarios.md`. No expected answers, previous diagnosis or candidate design was
supplied to the evaluator.

| Case | Observed action | Outcome |
|---|---|---|
| A: repeated single-state tiny gains; coupled-field/evolution goal | Plan one integrated comparison over early-growth, near-tip and high-growth states; retain reaction and strain/energy outputs rather than another sign check | Decision-scale choice; avoids micro-first default |
| B: uncertainty propagation; only interval widening established | Compare structured geometry/registration uncertainty with matched-marginal independent noise across origins/horizons; retain simple forecast | Resolves structure versus noise-scale hypothesis, not ten more one-frame magnitudes |
| C: known import rename | Fix the import and run the existing lightweight unit test | Proportionate; no ceremonial scientific redesign |
| D: used evaluation, sealed cohort, no new run authority | Develop a substantive proposal from permitted evidence; do not open the cohort, sweep models or claim fresh confirmation | Does not confuse ambitious design with expanded permission |

The first pass selected the right scale but A's candidate was underspecified.
The core was tightened to require the actual intervention and predicted causal
signature. A focused repeat of A/B then produced concrete candidates:

- A: shared damage-conditioned residual displacement head, fitted with
  strain/energy/reaction terms, versus the existing method; a displacement-only
  ablation only if needed to separate capacity from objective effects.
- B: smooth boundary-normal deformation plus shared registration perturbation,
  versus independent pixel noise at matched marginal scale and ensemble count.

Both are planning outputs, not validated methods or accepted project changes.
The repeat also kept reconstruction versus evolution evidence and development
observation agreement versus independent physical truth separate.
