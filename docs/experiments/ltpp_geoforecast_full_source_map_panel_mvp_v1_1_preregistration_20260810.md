# LTPP full-source map-panel MVP v1.1 — preregistration

## Relationship to v1

This is a new, one-shot engineering execution after v1 ended as
`IMPLEMENTATION_ABORT__NO_SCIENTIFIC_RESULT`.  The v1 process created only
three transient overlays and stopped during the fourth image because its
unbounded line-pair enumeration exhausted practical resources.  It produced
no result JSON, decision, manifest, or visual outcome table; no partial
candidate overlay was inspected for method selection.  The v1 output directory
is retained and is not overwritten.

## Status and unchanged boundary

`EXPLORATORY_FULL_SOURCE_PANEL_MVP__NOT_REGISTRATION`

spatial registration, extract controls, align dates, calculate residuals, or
authorize 2-D modelling.  All source files, dates, page number, long-line
minimum, rectangle geometry, pair rule, output colours, prohibited semantic
information, and no-manual-completion rule remain exactly as frozen in
`ltpp_geoforecast_full_source_map_panel_mvp_v1_preregistration_20260810.md`.

## One added computational guard

After deterministic 10-pixel line clustering, retain at most 24 lines in each
axis.  Rank first by descending detected segment length and break equal lengths
by ascending coordinate, then restore ascending-coordinate order before the
fixed rectangle enumeration.  This cap is the only v1.1 method change; it is
fixed before any completed eight-date output is read.

## One-shot stop rule

Run synthetic tests, then run all eight dates once into a new named output
directory.  Record every date.  Any `NO_PANEL_PAIR` is retained as a failure;
there is no second parameter change or retry under v1.1.
