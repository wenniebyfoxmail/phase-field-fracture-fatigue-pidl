# D01 D5：整幅几何参考与预测状态充分性验证设计

## 目标与已有结论

原问题是带观测不确定性的裂缝演化预测；当前可识别目标是下一指定名义荷载、同梁共同支持上的16格可见裂缝覆盖。继续这一目标，先解决观测参考与状态信息是否足够的问题；不回到宽度修补，不把目标悄悄换成分割精度或物理损伤真值。

复用D4完整结果：8主目标、3预热；保持P／原割线L／质量定位Q／同预算统一衰减U等梁空间误差为0.05000882／0.06859662／0.05063256／0.05080571pp。Q相对U仅低0.34%、4胜4负，整体未胜P。梁6较U低11.74%的局部收益保留，不能事后为梁6选法或继续调g。

这些是对冻结mask的开发重放。真实可见几何、漏检细裂纹、配准波动、状态不足，仍可能混在同一残差里。**现有数据足以设计与定位缺口，不足以独立标定完整观测误差或证明跨梁预测能力。**

## 1. 把可见几何、观测过程与物理过程分开

令x_t为在固定相机分辨率和可见范围内可分辨的裂缝几何；y_t为已有冻结mask的16格覆盖：

`y_t = H_t(x_t) + b_t + e_t`，`Δy_t = ΔH(x)_t + Δb_t + Δe_t`。

H包含视角、遮挡、照明、投影与坐标支持；b可包含系统性边界偏差，e含随机/重复观测波动。这只是误差分解，不预设独立高斯噪声，也不预设b恒定。x_t也不是不可见微裂缝或材料损伤场。没有独立约束，不能从单条y轨迹唯一拆出过程噪声与测量噪声；更复杂状态空间或切换模型不会自动解决这个辨识问题。

主量继续是16格覆盖；整幅参考必须同时覆盖裂缝和非裂缝区域，能够发现漏检、字母、孔隙、分支和边界混淆。可辨段长/连通性只作辅助：旧的部分合格段长、段数因资格随帧变化，不直接当成全裂缝真实长度或分叉数。尺度未独立核验前继续用参考像素与覆盖率。

## 2. 复用清单与真正缺少的独立证据

| 证据 | 已有资产能做什么 | 仍缺什么／不能替代什么 |
|---|---|---|
| 同梁14阶段、共同支持、固定4×4格 | 保持已有身份与聚合定义；复用全部目标和评分 | 共同支持来自全选阶段交集，不能当作起点可获得的前瞻支持 |
| 冻结整幅mask、既有不确定份额 | 可追踪模型输出和既有资格标签 | 模型自己的不确定标签、透明叠图满意度、另一个算法同意，均不是独立误差参考 |
| 30幅人工任务及重复、17个可见宽度参考 | 局部可见边缘差异、同一图像标注重复性 | 不覆盖整幅漏检／误检；重复同一像素文件不能估计重新拍摄噪声，不再追加宽度修补 |
| 现有面积、覆盖分布、部分段长记录 | 保留时序和局部异常线索 | 首末面积增加不证明每一步真实增长；面积相同也可能存在空间重分布 |
| 名义荷载、文件名时刻及先前日志关联记录 | 当前只能作给定下一名义荷载的条件输入 | 相机与记录仪同步误差、真实保载/卸载、加载速率与位移对应仍需可核验证据；不读新日志或新帧来补齐 |
| 梁6局部收益 | 后续机制假设来源，保留全部反例 | 已看过的两次改善不是独立确认样本 |

独立证据分为三个互补部分，不能互相冒充：

**R1：整幅可见几何参考。** 优先查明是否已有同试件、同阶段、同视面的原始高分辨率记录／来源清楚的独立人工参考；本轮不查阅新材料。若确实没有，未来只能安排独立审阅/参考制作，不让当前mask给自己作真值。默认参考包覆盖全部14个已曝光阶段，不只选梁6或表现好的格；将随机化、去阶段顺序的原图交给未参与当前mask制作的审阅者，不显示mask、预测、误差或荷载趋势。两位审阅者各自标记确定裂缝、确定背景、边界/细分支争议和不可判区，再对争议作有记录的复核；不同意时保留区间，不强迫共识。可以用独立工具辅助描绘，但自动结果不能自动升格为参考。用户无需逐像素重画所有裂缝；专家工作集中于整幅覆盖审核和争议边界。此工作未启动。

该参考能检验**同一图像上的算法偏差**；由于共享成像分辨率和照明，它仍不能证明亚像素微裂缝完整性或物理开口。若要物理几何结论，需要同阶段、更高分辨率或独立成像/量测及其尺度、对齐和误差说明；另一个时刻的照片不充当同步真值。

**R2：同状态重复采集与坐标误差参考。** 需要同一试件在结构变化可忽略的窗口内重复拍摄，以及不依赖裂缝mask选取的坐标控制及其误差。固定荷载本身不保证不变：保载蠕变、裂缝继续张开或相机移动均要通过加载/位移记录辨别。只有同状态成立时，重复差异才可约束采集/可见性波动。现有包没有已获资格的这类参考，不能把相邻加载阶段当作“零变化”对照；若找不到既有记录，就明确留空，未来采集属于另行工作。

坐标误差应在非裂缝独立控制点上核验，记录空间分布而非单一全图RMS；结构本身变形不能被当作相机误差消掉。这里只定义接收的控制点误差/变换范围，不重做配准、纹理流或开口检测。MD03如将来提供结果，先查适用对象、独立性和误差定义，不直接把它当作D01真值，也不向其派任务。

**R3：独立阶段/加载状态与未来评估单元。** 需要可核验的阶段—相机—荷载—位移对应、加载方向及保载信息。当前未知项保留unknown。之后若要作独立预测结论，还须从未用于设计的完整梁序列评估；本轮不读取、不选择具体留出，也不把14个已曝光阶段重新命名为盲测试。

## 3. 标定输出：先得到误差范围，而不是立刻生成概率

参考协议先于查看算法误差确定。每帧整幅分区导出：

- C：确定可见裂缝；B：确定背景；A：可见但边界/分支有争议；O：遮挡或分辨率不足、不可判。
- 在每一固定格及共同坐标支持上，C给出可见裂缝覆盖下界；C∪A给出可判部分上界。若O非空，另报O份额；只有把O全部计入上界才是整格保守区间，否则结果只能叫“已可判域覆盖”。不得丢掉O后继续声称原整格目标已被参考。
- 细裂缝超出可辨阈值不补零；参考列明最小可辨结构与像素尺度。可见长度另建固定资格、固定分支/中心线定义后才能用，当前主评分不切换到长度。
- 参考重复分歧、遗漏/误检、边界偏差、配准误差分开记录。微裂缝、分支、文字/孔隙、靠边界位置按预先空间分层展示，但不按误差删格或挑选目标。

先报告带符号偏差、原支持加权绝对误差及参考区间，沿用整格和等梁权重。空间相关的边界/变换要作为**整帧联合情景**传播；不能为每个像素或每格独立抽噪声，把相关误差平均掉。只有真实同状态重复足够且误差模型另经检验，才讨论概率分布、状态空间观测协方差或覆盖率。本设计不生产“95%置信度”、伪后验或校准g。

## 4. 如何区分真实演化与观测波动

对同一物理格，参考覆盖区间为[l_t,u_t]，相邻差的保守区间是 `[l_t−u_prev, u_t−l_prev]`。再把允许的联合坐标变换、参考分歧及有依据的同状态波动范围纳入同一情景集合。该区间可以宽，但不能用猜出的配准标准差缩窄它。

| 看到的证据 | 允许的解释／判别 | 下一步 |
|---|---|---|
| 冻结mask变化，但独立几何参考不变，差异位置可由已核验观测误差解释 | 有观测波动证据，不是物理演化证据 | 保留mask；量测解释限于可见参考，不拟合过程变化 |
| 独立参考的变化在全部合理联合误差情景下仍同向非零，且阶段/坐标关系明确 | 该可分辨位置存在可见几何演化证据 | 可进入这一目标的条件预测设计 |
| 变化区间跨0，或同状态波动未知 | 当前不可分辨；“未检出”不等于“没有演化” | 标为unknown，不造平滑真值、不强制单调 |
| 质量参考与加载阶段均明确，但同类可比状态之后的变化不同且超过观测范围 | 现有状态可能缺少历史/力学信息；也可能有未测因素 | 进入状态信息诊断；不能直接宣称存在模式切换 |

全裂缝面积差不能代替空间演化判别：一处增加、另一处减少可能抵消。全部8主目标的16格仍展示；可分辨/不可分辨标签作诊断，不事后剔除不可分辨格来提高旧评分。原8+3结果永久保留；独立参考下的评分作为另一个明确命名的结果，不能覆盖旧成绩。

若R1已有而R2没有，最多识别同图分割偏差与参考变化；不能把剩余全部归为过程噪声。若只有R2而无R1，重复性好仍可能存在一致的漏检与边界偏差。两者都不能单独替代对方。

## 5. 预测状态充分性：检验增量信息，而不是寻找更大网络

“覆盖+荷载”是否足够，无法由当前8次误差唯一回答。割线失败可能来自不可靠观测、非恒速变化或状态缺失；质量衰减未胜保持也不证明裂缝不可预测。以下为未来成组验证设计，当前不拟合/运行：

| 表示层 | 拟检验的信息 | 比较/有效条件 |
|---|---|---|
| S0：现时16格覆盖＋给定下一荷载 | 位置占据是否已足够 | 保持P为总体参考，旧P/L/Q/U只复用，不再调参 |
| S1：S0＋前缀覆盖历史及荷载间隔 | 是否需要发展速率/路径记忆 | 已有末两帧割线负结果是约束；不把换个名再跑割线当新验证 |
| S2：S1＋起点前可获得的加载状态信息 | 相同几何下，加载方向、保载/速率、位移或刚度信息是否改变下一步 | 只纳入经核验、起点前可用字段；不得用未来位移/目标质量/未来配准帮助预测 |

先以独立参考误差界定义“现时状态近似相同”，查同梁/同可比物理坐标、相同下一荷载条件下，是否存在**前缀相近而下一增量可分辨地不同**的情况。若对应的加载历史/位移不同，可形成遗漏状态的具体假设；没有足够可匹配状态就是证据不足，不能硬做高维条件独立检验。不同梁的格编号并非同一物理位置，不能将B4格7与B6格7当作重复状态。单个碰撞也不证明随机性或切换模式。

之后只有数据与独立参考允许时，才比较一个事先写明的有限记忆、含加载状态的非神经条件模型与同结构删去新增信息的控制；复杂度预算、历史长度、噪声设定和可用字段事先相同/明确，避免把模型容量增加当作状态信息收益。是否拟合、具体模型和预算需后续单独规定，本设计不授权执行。若新字段不存在，S2明确不可测，不用名义时间或图像暗度偷偷代替。

独立评估按完整梁分组、按起点前缀预测、固定下一荷载条件。支持域由起点图像/预先相机视场定义，之后不根据未来裂缝修补支持；未来不可见部分另报缺失/覆盖，不能当作无裂缝。当前14阶段只能用于开发诊断，不能据其结果挑模型后再称确认；同梁格、patch、相邻帧不当独立样本。过程更新与自主多步预测分开，当前目标仍只是一阶段条件预测。

## 6. 什么结果值得继续预测

不添加任意“提高5%”门槛，也不要求每根梁都赢。把值得继续的组件证据与整体预测结论分开。

1. **可见演化可辨。** 至少出现具来源清楚的独立参考、坐标与阶段对应的空间变化证据，且超出其观测解释范围。不能只看净面积增长或mask自一致。若变化持续落在未知观测范围内，优先改进观测/缩窄可辨目标，停止架构扩张。
2. **状态信息有额外作用。** 前瞻规定的新增起点信息与可分辨未来增量有一致对应，并在同复杂度删信息控制下减少未来误差。若仅改善面积抵消、只在事后挑出的梁6成立，保留局部线索，不宣布充分状态或跨梁收益。
3. **预测价值大于参考含糊度。** 主指标继续是16格原支持加权L1后等梁汇总。对同一联合参考/对齐情景r，计算 `G(r)=E_r(P)−E_r(M)`，再报告合理情景集合中的收益范围；若最坏合理情景仍为正，才有超出已列参考歧义的方向性收益。不能给P和M各挑不同“有利真值”；参考集合应先于模型结果确定，不能通过缩窄集合救分。

第三点是**充分的稳健性证据，不是唯一的推进门**：若总体区间跨0但预先定义的可辨部位重复获益，可保留组件并修复信息瓶颈；不能把局部胜利写成总体成功。极端保守参考包络下不明确，也不等于已经否定可预测性。

3根开发梁不足以可靠估计跨梁置信区间或实际收益阈值。要支持独立预测结论，还需之后完整新梁、已核验参考及前瞻冻结方案；观察到的改善应在独立梁上可复现、非单梁支配。实用最小收益应由未来的分辨率、决策需求和参考重复性给出；这些目前缺失，因此不声称已有实用门槛，也不把任意很小的正值叫工程价值。未具备这些条件时可以继续组件研究，不能宣称工程部署/真实道路预测。
