# D01 D5：原论文与既有归档的R1/R2/R3来源追查

## 结论

**能补齐来源与名义阶段说明，能找到有限的初始裂缝参考和同荷载多视图线索；不能从这些文件补出14阶段整幅真值、同步误差界或固定相机的零变化噪声标定。** 当前D01仍适合已曝光开发集上的观测/计量研究与名义荷载条件的基线诊断；已经完成的预测重放不升级为物理演化或独立预测验证。下一步的工作重点应是确定参考能覆盖的可见几何范围，而不是继续试预测器。

## R1：找到了试验前裂缝图，但不是逐阶段真值

数据原文“Data Description”（本地全文第31行）明确：Existing Cracks图纸与原始照片记录的是再次加载前的既有裂缝；摘要/前文（第12行）说明先测试未开裂梁、记录形成的裂缝，再测试预裂梁。图纸涵盖梁面及底/顶；v4实际目录名有RVT文件，虽论文称DWG，不默认为同一软件格式。

三梁的CAD打印PDF已本地归档，G4可见裂缝走向、各面标识及尺寸。因此，之前“限定材料未找到整幅参考”应细化为：**找到了全梁试验前裂缝图样这一独立于当前mask制作流程的候选参考，但没有找到当前14荷载阶段逐帧可见裂缝区域真值。** 图纸的描绘方法、最小可辨裂缝、画线宽度语义及定位误差没有因此得到标定；不能把图纸线条粗细当裂缝面积或宽度。10kN首帧也不能直接等同于图纸的试验前状态。

它能减少未来核查时对“原有裂缝在哪里”的摸索，但不能直接给14帧算面积/长度准确率。目录还记录每个IB固定视图2张尺标参考照片（合计6张），并有Existing Cracks参考照片；本轮未打开这些照片，不能给现有结果补毫米尺度或精度。

方法论文4.1的LVDT比较来自单裂缝后张梁的另一组试验；4.2对应当前多裂缝梁，报告的是选定一步的DIC/CMfM对比。不能把前者“几百分之一毫米”的精度作为当前3梁、14帧或冻结mask的误差界。原论文的对比曲线/少量表格也不能代替整幅逐阶段标签。

## R2：找到14组多视图拍摄的记录，不等于固定机位重复噪声

三份工作簿的 `Beam-seconds` 页为当前14停点提供了IB的3次移动拍摄时刻（C:E列）和恢复加载时刻（O列）。这些时刻在415成员目录中全部能找到对应IB-Free文件：**14组、42个成员名匹配**，只核目录，没有下载或打开。

对应移动拍摄发生在已记录停点之后6–29秒，均早于工作簿所记恢复加载时刻。方法论文4.2说明逐步保持加载、改变手机机位拍摄；数据论文第44行也说明每停点三张随机不同位置照片。因此能补齐“同名义荷载、多机位拍摄”的来源分组与候选时间窗口。

但它们不是固定相机同机位连续重拍；与选中固定帧不同时刻，也未独立排除保载变化/蠕变、视角遮挡、像差与局部变形。**不能把42张图直接当42次零变化观测，从差异估计纯分割噪声或过程噪声。** 文献称恒定加载也不是已测得的零几何变化证明；本次没有分析机器曲线来验证平台。

独立坐标控制点误差/空间误差界仍未找到。旧配准拟合残差和尺标照片都不能直接提供它；对比DIC算法也不能自动成为独立物理真值。若以后要用多视图开展一致性核查，需另行定义适用对象和批准访问图像；当前不执行，也不重复MD03的运动/纹理诊断。

## R3：手工对时与停点记录可补，精确同步仍补不齐

数据论文第31行明确相机与记录仪不硬同步：先启动时钟，手工记录相机与机器起点；Filtered Data按工作簿时刻调整。三份工作簿现已直接核对：

- G4当前IB Canon的启动记录为36秒、机器45秒；G5为3秒与49秒；G6为5秒与30秒。G5启动记录位于 `Beam-time`，另两梁也有 `Beam-seconds`。这些是记录中的共同钟时刻，不能再次把起点差机械加到已调整的Filtered Data，否则可能重复校时。
- 全14个当前选中停点的名义荷载与文件名秒数，都与 `Beam-seconds` 的A/B列一致；IB照片时刻和恢复加载时刻见C:E/O。已导出84个单元格的出处和值，方便复核。
- 说明补齐了**名义**位移控制2mm/min、25Hz机器记录以及位移字段语义：PosAbs为活塞绝对位置，Pos为接触后置零的相对位置，论文称对应梁中部位移。它不是裂口位移/CMOD，不直接换算裂宽，也不因此排除支座转动和接触柔度。

以上可支持起点/停点来源说明、名义加载阶段和后续状态输入的资格设计；2mm/min是试验说明值，不能当每个保载窗口或每个采样时刻的真实速率。

**仍未给出手工记时误差、相机抖动/漂移、严格触发对应或同步误差界。** 不能用0.020秒近邻查表差作为替代；此缺口目前无法仅凭已找到文件补齐。当前选取14个IB停点避开原S03-E004的末端表覆盖问题及另一IA末端标签冲突，但没有推翻旧身份核查的否定结论。

**推荐下一步：D01先作为“可见裂缝观测的计量与证据开发集”，保留已完成的8目标预测负结果。** 若继续准备工作，优先把试验前图样能覆盖的参考范围写入盲核查协议；不再要求用户漫无目的找材料，也不要求现在重画14张mask。只有未来实际获得独立可见几何参考、误差范围与明确状态输入，才值得重新准备条件预测验证。现有资料不是毫无用处，但也不能靠新增状态空间/切换/神经模型补出缺失真值。

本次没有启动盲筛、标注、多视图比对、尺度估计或新预测。旧mask、旧分数、旧清单不覆盖；新来源结论另存。
