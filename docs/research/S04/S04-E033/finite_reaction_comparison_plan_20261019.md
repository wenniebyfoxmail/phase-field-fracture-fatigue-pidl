## 1. 原目标、机制与唯一需要改变的判断

原目标是：从FEM合成全场锚点修复已暴露c20s4的PIDL状态，保留damage/历史界，同时让位移、驱动力与机械响应相容。当前问题聚焦：在同一实际E032起点、相同原网络隐藏特征与固定E030物理damage下，能否让**真实全域raw RMSE至少下降0.1%**，同时保持原11项不退化，并保护上下端反力误差？

力学上，`R=∂E_el(u,d)/∂(u,v)`；free残差范数只投影到自由DOF，反力投影到给定位移DOF，二者不能互相替代。固定hidden后UV是头参数的仿射函数，UV/u/v误差有精确二次式；raw是应变产生的能量误差，反力是应力响应，实际有限值不等同于其起点切线代理。应从真实有限raw目标与这些约束选择系数，而不是把共同下降符号当终点。

**主假设H1：** E033的“UV/raw代理折中+一次小步”选择方式遗漏了反力，且没有直接追求有限raw幅度；同一八维空间中，针对实际raw误差并纳入边界受力的整体选择可能跨过原目标。

**竞争解释H2：** 受u_Z等精确曲率约束时，八维平面的可用有限组合不足；同一原802维UV头中的平面外自由度有实际用途。

**剩余解释H3：** 两种空间的预算内搜索都可能受非线性/约束几何/数值条件限制；未找到解不能直接证明空间、整个网络或固定damage物理上无解。

## 4. 统一参数化与不可放宽的约束

起点θ0∈R802，半径 `R=.02||θ0||=0.039821608331992`。

- F8：`θ=θ0+R B8ᵀz`，`||z||₂<=1`，旧八轴及顺序逐位锁定；不新增/删除/旋转轴。
- F802：`θ=θ0+Rh`，`||h||₂<=1`；仍是原输出头容量，不扩hidden或架构。

共同最小化真实原生Q4的 `q_raw=raw_global_MSE(θ)/raw_global_MSE(θ0)`，不再最小化UV/raw切线epigraph。目标成功必须实际 `sqrt(q_raw)<=.999`，即 `q_raw<=.998001`；当前分母raw RMSE=49.04943223781235，实际阈值 **<=49.00038280557454**。0.1%沿用工程幅度门槛，不宣称参考不确定性或物理/统计准确性界。

### 4a. 原11项实际保护保持

全域/Z的UV、u、v六项；全域/Z的raw、active四项；free-force平方一项。全部实际平方比值 `q_i(θ)/q_i(θ0)<=1`，无事后slack/clip；global UV RMS仍要求 `<1−1e−8`，raw以更强0.1%目标决定成功。damage物理界/预裂纹、原history/fatigue、所有非UV参数与实际NN前向一致性保持原检查（字段数值容差1e−10，身份逐位）。不通过FEM target damage替换或node投影救援。

### 4b. 原11项冻结切线锥也保留，并使两臂真正嵌套

锁定E032起点的原11×802梯度g_i及原κ=.04418604213300339。共同固定尺度 `s_i=||R g_i B8ᵀ||₂`（就是原8维投影梯度范数，均为正）。在物理归一头增量h上，两臂都用

`(R g_i·h)/s_i + κ||h||₂ <= 0`。

F8代入h=B8ᵀz，严格还原原E033的11个锥；F802沿用相同分母和κ，不能换成full802范数重新调margin。因为B8正交，`||B8ᵀz||=||z||`，8维可行点准确嵌入802维。由此目标、半径、原保护不随臂变化，只有允许的方向空间不同。冻结锥是本路线的附加搜索约束；两臂都失败不能解释为删除锥后/更大半径/整个网络也无解。
