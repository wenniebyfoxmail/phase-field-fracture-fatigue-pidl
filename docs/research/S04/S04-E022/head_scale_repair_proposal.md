# 单项最小修复提案：固定全质量 RMS 输出头参数化

状态：方案，未实现／未训练。依据 S04-E022-D001 六终态诊断；不是确认“头部是唯一瓶颈”，也没有量化头部单独能否达到 .001。先做函数等价和数值检查，再独立 Code Ready；新的生产仍须具体方案与运行批准。

## 一个问题与一个因素

问题：在不增加表示容量、训练预算或更改目标的条件下，固定输出头尺度参数化能否把现有下降方向转化为更好的 c60/c83 拟合，同时保留 c20？

**明确以 E022 为直接对照，保留末层 leak=.01，仅新增固定头部逐列 RMS 尺度缓冲。** 不回退为 E021 ReLU，不改其它激活／坐标／物理window/BC/backbone/损伤/history/fatigue。仍为三态 c20s4/c60s4/c83s4、alpha.7、seed7，每态从原 E017 backbone和相同零输出残差初始化新做10000更新；不接着现有终态训练。E019/E021仅作共同历史对照，不重训。

本轮发现 c60 恢复了空间特征和隐藏梯度，当前两区方向一致，却到达更差终态；c83还有非零头梯度且谱能量集中。它们支持一个低成本的优化参数化判别，但**未证明列 RMS 失衡是原因**。逐列缩放不能消除所有列相关性或补充缺失的空间特征；不把这项方案描述为已找到根因。

## 固定定义，避免终态调参

在任何更新前，用该态原始共同初始化的实际 E022网络计算隐藏特征 h0。令 f(x)=BC(x)×window(x)，w_i=mass_i/Σmass，

```
Phi0_ij = f(x_i) * [h0(x_i), 1]_j / abs(Us)
s_j = sqrt(sum_i w_i * Phi0_ij**2)
s_max = max_j s_j
D_j = 1                           if s_j == 0
D_j = 1/max(s_j, 1e-6*s_max)       otherwise
UV(x) = backbone(x) + f(x) * ([h(x),1] * D) @ B
```

全部284列包含bias，u/v共享该向量；D是固定buffer，不是可训练参数。s_max非正、非有限或缩放／前向／梯度非有限即停止。零列不从终态或目标补造尺度。相对floor1e-6在任何候选训练前固定，作用是把非零列的最大放大倍率限制在共同尺度1/s_max的1e6倍；它尚未经本项目实测验证，不扫描或按状态改变。全节点质量校准只读输入、共同初始化特征和已知载荷Us，不用目标残差、已训练E021/E022特征或最终误差确定D。

D全程固定，无batch依赖；无新增RNG抽样、中心化、旋转或额外训练参数。物理支撑与边界条件仍由相同f控制。原零输出头B=0应保证三态初始UV逐值等于原backbone。对任意固定D>0，令物理头B_phys=diag(D)B，则原函数类不变；验证该函数等价是实现准入，不能只检查参数量。

## 实际优化与停止规则

同一 AdamW 参数、原生 CosineAnnealingLR(T_max=10000,eta_min=1e-5)。每次更新前读取实际LR，optimizer.step后scheduler.step；首个.001，最后实际约1.0000024427270673e-5，post-final才1e-5，无10001。与自身E022直接对照的实际10000LR和采样序列逐项配对。隐藏与头部仍各做恰好同一10000次更新，没有额外头部拟合／头部专训阶段。头部参数化会通过后续联合训练改变隐藏特征的学习轨迹；即使改善，也不能将收益解释为冻结特征下的纯头部最优收益。

这项变换改变 AdamW 的梯度、动量和参数步在物理头坐标中的几何，正是被检验的因素。原scalar decoupled weight_decay保持1e-8；固定D与乘法衰减可交换，所以对应物理头B_phys仍乘同一(1−LR×wd)因子。不要把它误说成保持了Adam更新路径或改用了相同坐标下的L2优化。

任何引用／hash／三态配对／映射／D向量／activation／backbone冻结／原生LR／stream／finite／archive／预算检查失败即停，保留现场，不自动换floor、换GPU、加步或重投。正式评估最终更新10000；中间0/1000/...10000仅被动轨迹，不选最好点。

## 验证什么，如何决定

实现阶段先做三态初始化函数等价、参数/RNG/输入身份、固定D与manifest、实际LR/sampler、tiny-σ/零列/坏摘要拒绝及有界内存的非训练检查。因参数化改变，明确检查新头梯度与原物理头梯度的关系 g_new=diag(D)g_phys；这些是代数检查，不是训练收益。

生产候选仍以**三态最终全场归一化质量 UV RMS均<=.001**为原主目标；分别报告相对E022直接对照及E021/E019历史对照的全场／损伤／背景和窗口内外背景误差。重点c60恢复、c83改善且保住c20；不能拼接各状态赢家。当前观察到的误差量级不构成已证明可达的修复上限。

诊断同时在原未缩放的物理特征Phi和新参数化中报告头部残差；不以仅缩放后变小的梯度范数声称收敛改善。D初始化身份和全程不变必须可核验。尺度统计／头部残差改善但UV不改善，只是组件变化，不能救回主目标；保留负结果，不自动延长训练或接着扫floor。若无任务收益，再据实际损伤特征和梯度选择新的表示判别，而不是把此方案追认为成功。
