## 数学组件：精确局部导数与近似物理度量分开

下列所有场向量只含自由位移DOF，不含反力。q(theta,a)为位移场，E为固定d的原弹性能，
R=grad E，K为相同原生Amor分支切线；B=∂q/∂a，J=∂q/∂theta，H=BᵀKB。
在**固定秩／固定局部头坐标**且BᵀR=0的邻域，令

```
C_ij = Rᵀ (∂B_i/∂theta_j)
U = Bᵀ K J + C
Q = J - B H⁻¹ U
Z = J - B H⁻¹ Bᵀ K J
M = Zᵀ K Z + lambda I
gE = Qᵀ R
gR = Qᵀ Kᵀ R                 # .5 ||R_free||² 的导数
```

Q是包含移动特征项C的局部消元导数；Z只用于Gauss–Newton式物理度量，**不是Q，M也不是精确profile Hessian**。
计算Cᵀ时R须detach，不能额外求导R。H不加ridge、伪逆或rank修补；非SPD/未解准停止。
核查Q/Qt、U/Ut、J/Jt、C/Ct伴随及有限差分；记录QᵀR与包络JᵀR的差而非删去C。
Amor trace=0处仅有分支／单侧意义，跨支后必须看真实有限场。

**actual Phi与动态SVD仍是适配器的未解决项。** 初始直接复用已保存Phi/T，不重建零状态。
固定局部图公式不能无声套在动态SVD秩／投影变化上。锚定Phi差分可作为实现候选，
不因写出公式就认可其与真实网络等价。未来适配器须同时验证：源读数不变、Q对真实head-closed
有限变化导数有效、每个有限候选重存当前Phi并达到1e-10、真实NN安装后字段最大差≤1e-10。
秩或图变化使导数检查失效时停止，不通过放宽阈值、强制旧秩或把锚定线性场伪装成NN绕过。
本轮人工测试**没有**验证上述真实适配器条件。

## 未来候选政策（提案，未执行）

隐藏坐标采用可逆固定缩放：每个隐藏tensor l的s_l=max(RMS(theta0_l),1e-3)，
theta_l=theta0_l+s_l sqrt(n_l) xi_l；s_l在整轮固定，J/C均对xi求导。
参数信赖球||delta xi||₂≤0.01，因此各层相对RMS步长受限；这不是网络容量界。
同时限制||Q delta xi||_lumped-mass≤0.01||q0_free||_lumped-mass；质量来自原网格且必须严格正。

lambda=1e-3×max两条确定性方向的ZᵀKZ Rayleigh值。方向用seed=1的Rademacher流产生并归一，
只生成一次、存字节及hash；无正有限尺度则停止，不扫描lambda。两个M逆作用各用至多64CG步，
实际相对线性残差≤1e-4；不收敛即停止，不拿未解准方向宣称共同下降。

令u=M⁻¹gE，v=M⁻¹gR，a=sqrt(gEᵀu)，b=sqrt(gRᵀv)，固定
`p=-(u/a+v/b)`。精确SPD解在两梯度不反向时给共同下降；实际必须核查两个斜率均负。
零梯度、相反或数值无法分辨时停止并记录。采用Qp约束物理步，不用Zp冒充真实消元变化。
每宏步只尝试alpha=1,1/2,1/4,1/8，按序取首个通过者，无权重／步长网格搜索。
每候选必须是真实NN字段、重新闭合头部、固定状态一致、E在旧128eps算术容差下不增且Ru严格下降。
Ru的严格下降是候选接受政策，不是新科学成功线；旧能量方向margin>1e-10与旧比较基准保留。
active/FEM字段只评分，**不使用FEM active标签求导或训练**。
此政策同时加入残差选择和消元，收益只能归于联合政策，不能单独称预条件收益。
