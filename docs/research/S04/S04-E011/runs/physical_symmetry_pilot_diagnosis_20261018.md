# 200步软对称未胜过control与预裂纹damage差异：只读诊断

## 问题与结论

本次只重放已保存三个端点网络的前向输出、读取原FEM初始/末态与固定history；训练更新0、新FEM0。已确认约束确实连接完整物理u/v且梯度非零。它降低了相对初态的训练对称损失，但没有使候选胜过control。预裂纹也并非两方法共享的永久固定二维damage场：FEM硬固定裂纹线，PIDL只初始化软罚历史；裂尖附近的初始横向轮廓也不同。

## 1. 对称损失：先排除“只因展示口径不同”

网络直接输出，使用与runner相同的9280对探针、同权重与Uref=.12：

|端点|完整位移镜像损失Lu+Lv|
|---|---:|
|原始|6.19624e-7|
|control200|4.38184e-7|
|候选200|4.76186e-7|

候选对原始下降23.149%，control下降29.282%；候选对control高8.673%。同样探针换成原生Q4重建后，control3.47114e-7、候选3.88367e-7，候选仍高11.885%。直接网络局部展示窗control2.62780e-6、候选3.04051e-6，结论也相同。因此支持范围和重建差异存在，但不能成为未改善的完整解释。这里局部窗用x[-.04,.08]241点/y[0,.04]81点与其镜像；旧图全窗161行的轴线权重略不同，不能把两个数字直接混用。

训练探针半权重给全域内部、半权重给x[0,.5]/|y|<.04；旧展示包含负x预裂纹，强调近裂尖局部。这解释了训练指标下降与局部某分量未下降可以并存。该检查进一步证明，即使消除这项差异，候选也未胜过control。

## 2. 优化机制：不是把场投影成对称

实际目标是log10(Eel+Ed+Ehist)+1e-5*weight_norm+lambda*(Lu+Lv)，lambda=.1271802；初态lambda*grad(parity)的L2范数仅为物理项1%。damage直接对称系数为0。训练没有每步对称下降、局部下降、投影或线搜索条件。

RPROP更新使用“总梯度符号×自适应步长”，不是按梯度大小缩放位移。按初态全参数梯度L2标定1%，不等于对称优化移动1%，也不保证任何探针区域损失单调下降。小惩罚可以改写一部分参数符号并改变后续步长/路径；不能据梯度范数推约束有效强弱。

日志另显示fresh RPROP第一步使两臂原物理总能量均升约9.4倍；200步在回落到原值附近。候选parity从第一步约1.23e-4逐渐回落至4.76e-7。它不是继承原optimizer状态的小幅续跑；有限200步终点不能解释成受约束最优解。候选端点联合目标也未低于初始。已确认的原因是弱软约束/联合目标/符号优化与固定预算未确保定向下降，非helper未激活。仅凭这两个臂不能把control更好的所有路径差唯一归因于lambda、重启或某一局部梯度冲突；不声称“增大lambda或多跑必定解决”。

scalar float32总loss上lambda*parity初值约7.88e-8，可能小于该处一个ULP；但这不删除autograd支路。标定的parity梯度范数.0183524、物理梯度.2334065，均非零；因此不能把打印loss相同解释成未加约束。

## 3. 预裂纹线：FEM硬条件，PIDL历史软条件

直接读取common_common_initial.mat/free_dof_d：FEM恰好排除251个节点，全部位于y=0,x[-.5,0]；初始和c1s2这些节点均d=1。

PIDL的source/utils.py::hist_alpha_init只生成历史下界。SENS_tensile/field_computation.py::fieldCalculation的damage直接等于alpha_constraint(NN第三输出)，没有裂纹线mask或硬提升。原生Q4不可逆项为gamma/2 * integral ReLU(hist_gp-d_gp)^2，gamma=16875；不是精确节点等式，有限GP罚不能保证线节点d=1。source/model_train.py::commit_damage_history在previous_accepted_nodal模式直接接纳上一步场，未取历史最大，也未重置预裂纹线。

## 4. 弥散带：两边都不永久固定，裂尖初始还不同

在远离端点的负x裂纹内，PIDL的解析AT1历史近似d0(y)=max(1-|y|/(2ell),0)^2, ell=.01。这是一条带形历史，不是整带d=1。

FEM只在上述线节点硬设1，横向profile由零载phase recovery求得，其余节点可随加载/历史变化。PIDL横向则由解析距离轮廓初始化history，再由网络能量/软罚求解。即使同ell/同线段，也不等于同一个初始二维damage场。

原生Q4统一重建的例子：x=-.25,y=.01，PIDL解析初始.252034、FEM恢复初始.251794，几乎相同；x=0,y=.01，PIDL解析初始.249579、FEM恢复初始.107677，已经不同。x=0初始正质量中心化宽度分别.00635910/.00502090。本轮原PIDL末态.00649259，FEM末态.00516577；该差有明显的初始场来源，不能全算训练新产生或位移不对称造成。

## 判断和后续边界

上一轮active约1%组件收益不能解释成约束有效降低不对称。下一步先把“要共同固定的是裂纹线d=1，还是共同初始二维场”写清；若选择FEM式预裂纹硬条件，需作为显式方法变更对齐PIDL输出语义并从合法共同初始化评估，不能后处理覆盖当前损伤、继续沿用不兼容历史并称公平修复。位移约束应先验证同一物理场/同一探针的定向下降；RPROP下不能只靠初始梯度L2比例选择权重。这里没有改训练代码、追加训练、重新求FEM或扩展轨迹。
