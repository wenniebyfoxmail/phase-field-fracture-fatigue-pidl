# 冻结 c20 PIDL：隐藏更新方向与物理预条件诊断（2026-10-20）

目的：定位PIDL降低能量却不能同步降低位移残差和active场误差的原因，继续服务于PIDL复现FEM。此为已完成Run的方向诊断，不是新训练结果，也不替代D6混合路线。

本轮：复用同一c20s4/rawstep99/U=0.11999988、native Q4/2×2GP、eta=0的17个节点字段/force、actualPhi投影向量及line-search记录；全部8对都分析，16个真实子更新与8个合成更新分开。FEM参照仍是独立重启、条件收敛的outer18（原s3历史，history commits=0），不是新的完整轨迹或物理真值。FEM damage、原UV边界、实际Phi存储/复用、B0/约束Q4 damage路线与1e-10保持不变；所有原始9个闭合头向量仍达标。没有NN forward/backprop、Phi重建、SVD、参数更新、FEM求解或历史提交。

## 2. 方向已经不同，单纯缩步不能解决全部问题

固定d时，E的节点梯度是R。局部一阶量分别是：

- 能量变化方向：Rᵀδq；
- 半残差平方方向：RᵀKδq；
- active平方误差方向：2Σw(active−active_FEM)δactive。

16个真实子更新都降低E，但4次头校正的RᵀKδq>0，恰好对应4次R增加；hidden的2次、active的各4次也已在起始一阶斜率中呈现。故这些局部增幅不是只由大步过冲造成；沿同一方向减小正步长仍会先增加对应误差。最终头部g∞=3.9319e-11只说明当前actualPhi投影ΦᵀR闭合，并不要求完整R最小，也不要求active误差最小。

解析处理拉压trace跨支后，能量功+路径曲率闭合误差≤2.417e-18，路径平均切线force差≤3.155e-17；32次小扰动FD最大相对差1.018e-6。真实子更新有14–732个GP严格跨支，起始zero-trace GP均0。该精度下，观测到的分歧可由方向/度量解释，无需用本轮空间算子错误解释；这不替代完整damage/history算法的审核。

active积分下降1.970103e-6，而压缩能量反而增加3.16315e-8；因此不是靠降低压缩能量“掩盖”active。本轮8次UV头校正中，4次Ru上升伴随active误差下降（第2/5/6/7对），另4次Ru下降伴随active误差上升（第1/3/4/8对），没有一次两者同时下降；这是该状态这8步的事实，不是两个指标普遍不可兼顾，也不构成取消头部闭合要求的理由。头部校正本身也会降低active积分（−5.42535e-7）同时增加active场误差平方（+3.17878e-6）：积分减少与空间分布变准是不同目标。

## 3. 隐藏方向与预条件：已测到什么，仍缺什么

8个实际隐藏位移增量与节点−R的Euclidean余弦只有0.001696–0.005198，接近正交。每对重启L-BFGS，没有跨步拟牛顿曲率；8个首次线搜索试探的最大能量是各自起点的9.30–152.96倍，随后回退接受有限下降步。这支持当前参数方向／步长尺度不理想，但本轮没有保存并使用完整隐藏J或梯度向量，不能识别其谱、各层贡献或唯一因果。

局部参数梯度经网络J_h映射后，节点方向一阶形如−α J_h J_hᵀR；这个非均匀映射与节点−R不同。随后输出头作的是弹性能校正。此为算法的局部解释，不是本轮实测隐藏kernel或容量证明。

在预定initial/head4/head7三个起点，保持相同边界、FEMd，并把各节点方向归一到对应实际隐藏步的节点L2长度。以下是initial的固定α=1回放（均为物理节点反事实，**不是可安装、达1e-10的新PIDL checkpoint**）：

|---|---:|---:|---:|
| 原实际隐藏方向 | −5.76211e-8 | +0.000666% | 6.105135 |
| 节点能量方向−R | −2.48983e-5 | **−37.0847%** | 6.091663 |

head4/head7上节点−R也分别降低Ru17.17%/23.94%，而实际隐藏步只降低约0.00635%/0.00196%。这说明在当前节点物理空间，E、Ru与active可以一起改善；不能据此说网络具有同样可达方向。−KffᵀR更偏向力残差，Jacobi更明显改变active误差，预条件会改变改进分配。

物理对角最大/最小比约3.5573e4（**不是全局K条件数**），没有零/负对角；最小1%对角DOF承载约7.1%的残差平方。Jacobi未加floor/ridge。但物理Jacobi并非自动安全：initial上固定分支的局部能量二次步α≈183.65，实际跨7844个GP分支，Ru反升81.77%；局部残差二次步α≈153.62则Ru降39.31%。两者均只作一次已声明回放，不是线搜索最优点，更不是NN预条件训练成功。完整15个方向/所有固定与解析预测步都保存在CSV，没有挑选最佳场端点。

## 4. 空间位置与下一项决定

最终active误差平方质心约(−0.22633,−0.000252)，主要仍沿左侧y≈0的裂缝带；其落在FEM参考最高1% active GP支持内的份额只有0.49046%，即误差平方主要位于这个参考支持之外。该top1%按参考GP面积权重定义并保留阈值ties，不是新成功指标或热点IoU。全局R²正增量质心约(−0.11899,0.05580)，负增量质心(−0.08447,−0.00749)，显示不同位置的增减相互抵消；质心只是描述，不能把共位当成隐藏参数因果。第2/6/7次头校正的R²正增量质心分别约(−0.1076,0.0528)、(−0.0859,0.0572)、(−0.0928,0.0561)，均是分散贡献的重心，不是峰值坐标。各真实head/hidden阶段的正负R²位置另见component_force_localization.json。

结论：本轮直接定位的是**方向／度量瓶颈**：真实更新沿能量下降方向前进，却在部分步骤沿残差或active误差上升方向前进；隐藏参数条件与网络表示可达性的责任仍未分开。头能量校正在部分步骤增大全局残差，active又是另一种局部场误差。不能仅靠更频繁校正或把已闭合头部阈值收紧来判断复现FEM，也不能宣称容量已到极限。

下一项建议是直接比较保留实际Phi/头部消元的隐藏物理度量预条件或信赖域方案与本次重启首步策略，预算按实际调用对齐，同时看Ru和active；需要取得J_h作用并检验可达空间，而非将节点Jacobi直接当作隐参更新。本轮只完成诊断，未追加该训练或改写D6整体路线。
