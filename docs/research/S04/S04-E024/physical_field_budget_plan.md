## 统一尺度：预算衡量变化，保护衡量误差

节点质量m、GP积分w、自由节点和所有节点／GP分区沿用原定义。节点UV为二维向量norm；应变为原工程剪切向量(exx,eyy,gamma_xy)的既有比较norm，不偷换成张量Frobenius。R取full／damage／background／inside_background；节点d>.1与GP插值d>.1分区分别固定，评分不随候选改变。

记N_U,R为固定区域的节点质量L2，N_e,R和N_p,R为原生GP积分L2，N_F为原生自由力质量对偶norm（包含原rho尺度）。定义永久基线误差：

- e_U,R0=N_U,R(U0−U_FEM)，e_e,R0=N_e,R(epsilon0−epsilon_FEM)。
- e_p,R0=N_p,R(p0−p_FEM)，r0=N_F(F(U0))=rho0。

原比较的条件质量RMS／absUs或相对FEM norm用于报告；约束在上述固定原始平方积分上等价执行。不能用近零的FEM背景driver norm当预算分母。所有分母需由正式实现的零扰动核验写入不可变receipt；如分母为0，对应场变化须精确0，不加epsilon或自动切换尺度。不能仅从旧relative error CSV猜测原始尺度。

**物理变化预算**统一定义为

Q(delta)=max{ N_U,full(U−U0)/e_U,full0,
              N_e,full(epsilon−epsilon0)/e_e,full0,
              N_p,full(p−p0)/e_p,full0,
              N_F(F(U)−F(U0))/r0 } <= eta。

四项均以不可变E023中心计算，即使重新线性化也不移动累计预算中心。这里最后一项是**力向量变化norm**，不是|rho(U)−rho0|；后者会遗漏力方向旋转。driver／force预算最终用真实非线性场核验，不用切线代替。

预定eta={.1,.3,1.0}：分别允许校正场norm达到初始对应误差norm的10%／30%／100%（力为初始残差norm比例）。三档以当前误差尺度覆盖小扰动至“修正量与原误差同阶”，用于观察曲率与物理约束何处开始主导。**它们是探索信赖域，不是应用容差／物理安全标准或新路线触发线**，不保证达到边界、同预算耗尽或同数值步数。三态应用同档eta但不同绝对尺度，必须逐态公开四项绝对分母及实际花费。
