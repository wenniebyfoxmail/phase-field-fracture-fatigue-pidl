## 2. 顶层设计的问题：把四个问题分开

1. **信息集问题**：部署只能用当前／过去PIN状态、载荷和几何；不能用FEM场、event归一化寿命、
   未来event或按已见误差挑选的切点充当阶段。C1–20／21–40／41+是固定分析窗口，
   不是已证实的物理阶段；跨Umax同cycle不自动同状态。
2. **表示问题**：全局平均q会丢掉相对该平均量而言的空间分布信息；但原32列仍有局部／邻域量，
   不能说整个模型没有过程区信息。新增一列交互只让某个raw方向随q变化，
   既不让全部系数按状态独立变化，也不辨认何时该使用哪类校正。其充分性未知。
3. **目标分配问题**：目前优化一个raw残差的全阶段加权平均，用同一组系数兼顾三窗口。
   晚期单独变好不是这个平均目标的必然结果；反过来，晚期不好也不证明全阶段优化必然冲突。
   暂不同时换目标、表示、归一化和正则，以免下一次又无法解释改善来自哪里。
4. **主张问题**：damage/history被固定为V0，当前并不是“多个变量共同优化”的实验。
   也不是Pareto算法测试。拟合的是未截断残差，评价的是非负重构输出；这种映射差别保留，
   是否对晚期有影响尚未归因。单轨迹已见开发增益不能变成物理／泛化或部署结论。

因此先不增加NN、多头、更多proxy或完整状态门控。最便宜的下一问是：
**在原32维表示不变时，仅让训练目标专注晚期，能否减少已见U0.11晚期误差？**
它先区分“阶段目标的分配是否值得改”，而非再猜一个状态变量。未来若有信号，才有理由
讨论部署可用状态驱动的系数／校正选择；本提案不预先承诺该架构。

### 记录的能力边界

冻结CSV是每cycle误差平方／边界摘要，不是有符号空间残差、过程区状态或训练损失。
仅凭V0和B32的MSE不能恢复两者误差内积，不能可靠求出最优Delta衰减／混合系数，
更不能反推出局部阶段或梯度冲突。因此本轮不从曲线挑“关掉校正”的阈值，不计算或宣称归因比例。
原样保留R002图即可说明已知结果；本设计没有新增数值图、统计检验或“更严格”的通过门槛。

| 项目 | 唯一拟定方案 |
|---|---|

| 固定共同尺度 | 直接复用B32的h_T/r_T、xm/xstd、ym/ystd和2048采样位置；不对晚期或评价数据重估归一化 |

| 工作量 | 一个新Run，一次新求解／拟合、一次候选评价及同次表图；无调参、第三臂、重放或自动重试 |

设训练case k的三个窗口cycle数为n_ks，原训练样本权重为
`w_B(k,c,i) = (1/3 cases) × (1/(3*n_ks)) × area_i/sum(sample_areas)`。
候选权重固定为：

```text
w_L(k,c,i) = 0                                             c ≤ 40
           = (1/3 cases) × (1/(n_k−40)) × area_i/sum(areas) c ≥ 41
```

其中两式的area均是同一2048采样位置上的面积归一化。两臂损失总质量均为1、alpha仍1，
不因116／236样本数改变正则系数。候选仍有相同33个求解参数（含截距），不增加表达维数。
早期训练数据只参与已冻结共同尺度／归一化及必要lag上下文，不参与L32损失；不能声称完全没用早期信息。
此比较隔离的是训练权重干预及其数据贡献变化，不足以唯一归因到物理阶段冲突。
L32仍在全部121周期评价，不在C40／41处切换模型或按评价误差关闭Delta；固定窗口不是部署规则。

## 5. 轻量判据、分支与停止规则

唯一主量仍为U0.11固定C41–121，等cycle／native-area的
`R_late = sqrt(MSE_L32_late / saved_MSE_B32_late)`；基线为R002的4409.534774880898。
未来必须先核对其Run／单位／支撑／窗口身份；不得为省事把历史选优V1当这个B32。
EPS=1e-10只区分浮点持平，不设5%／10%、p值或全变量／全阶段获胜要求。

| 有效完成后的观察 | 允许结论和下一决定 |
|---|---|
| R_late < 1−EPS | 本32维设置下，晚期训练重分配有开发方向性信号。微小收益标弱；报告早期／中期／等阶段综合代价，不要求同步改善 |
| 晚期改善、早期退化 | 可观察到这次权重干预的阶段代价，支持继续设计如何分配校正；不证明真正Pareto前沿／梯度冲突 |
| 晚期及早期都改善 | 权重改变有用，但没有观察到“必须牺牲早期”的证据；不强行解释为阶段冲突 |
| R_late在1±EPS内或更大 | 停止此权重候选，不追加权重／proxy／alpha搜索；仍不能排除表示、支撑、正则或其他未测原因 |
| 输入／数值无效、主量不可识别或触限／不完整 | 分别报告，不当成物理反例，不重试／扩预算／现场换设计 |
