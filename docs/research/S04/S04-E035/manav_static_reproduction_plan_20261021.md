| 项目 | 固定设置 |
|---|---|
| 几何、物理 | [-.5,.5]²；初裂缝[-.5,0]×{0}；平面应变，AT1/AMOR；E=1, nu=.3, Gc=.01, ell=.01；无疲劳，残余刚度0（论文具体η未明示，记录此选择） |

| FEM | CITPC12现有GRIPHFiTH Q4、2×2积分；裂缝节点α=1；先零位移recovery，随后其收敛原场作为损伤历史；TOLir=.001，recovery罚项容差.001 |
| FEM求解 | Newton残差1e−6/max500；交错同一状态新鲜Ru+Rpf≤1e−4/max1000；仅任务目录中的有界Newton/残差线搜索，原生组装/MEX不变；完整记录此实现相对论文描述的差别 |
| PIDL | 8隐藏层×400，TrainableReLU，m0=3，Xavier seed1；log能量+L2权重1e−5；TOLir=.005；无额外初裂缝α=1硬mask；解析初始history；不以FEM解监督 |
| PIDL积分/优化 | 作者T3网格与单点能量积分，采用本机作者源实现的不可逆罚项；首步L-BFGS后RPROP，其后RPROP；lr1e−5、步长[1e−10,50]；最多10000步/状态；相对损失变化5e−6连续10步 |

论文FEM和PIDL的TOLir不同，按论文分别保留，不改为同一个数字。
首轮只运行seed1，回答一条轨迹的可复现性，不声称完成论文8初始化的均值/方差复现；其余种子在实测成本后另行安排。
本机作者细网格为100742节点/200791个T3，面积1，已通过几何/方向检查。粗网格文件身份尚未确认，因此首步直接在细网格执行L-BFGS→RPROP，不擅自重命名粗网格；这是相对作者本机训练流程的实施差异。原文未规定L-BFGS细节，本轮使用本机作者式lr=.5、max_iter20000、history250、strong_wolfe、机器epsilon停止；log为本机代码的log10。
