## ① 做了什么

[论文原文] 用神经网络表示位移和相场，通过最小化含不可逆罚项的能量求准静态脆性断裂。这里的 static loading 是逐步增加位移、各步求平衡并继承损伤历史（§2.2），不是单一载荷点，也不是动力或疲劳实验。

[论文原文] §4.4.2 专门考察剪切导致裂缝转向。SEN 为 1×1 方板，初始裂缝从左边界到中心。剪切角 ω=0；Eq.(29) 给出底边 u=v=0、顶边 u=Up、v=0。AT1、体积/偏量能量分解、平面应变、ν=.3、ℓ=.01（§2.1、§4.1、§4.4，Fig.8）。

[论文原文] Fig.11 在 Up=.4 比较 NN/FEM 位移和相场；裂缝向右下方转向，图示接近。Fig.13 比较弹性能和断裂能；NN 起裂/扩展临界载荷略高。作者明确说明 FEM 在 Up>.4 出现收敛问题；Fig.12 的 Up=.47 只有 NN，不能当成该处已与 FEM 验证的一对结果（pp21–23）。

- [分析判断] 明确给出 FEM 的收敛范围，允许把共同验证范围与 NN 延伸分开解释（§4.4.2）。

## ③ 局限

- [论文原文] Up>.4 没有成功 FEM 对照；Up=.47 的 NN 解不能仅凭图证明其定量正确。作者也说明此法对单个边值问题计算开销高于 FEM（结论，pp27–28）。
- [分析判断] 这是理想化、准静态、合成算例；不建立道路裂缝、接触/摩擦或循环疲劳有效性。
- [未明确给出] 本次定位的原文章节未给出剪切全部载荷步的数值列表；没有核定残余刚度的具体数值、完整求解器执行轨迹或 NN 每步训练成本。不能补成已知条件。
- [论文原文] 该 v1 的 code availability 仅说发表时公开（p28）；本轮未据此认定当前能获取与此版本绑定的完整代码。
- [分析判断] §4.5 的分叉示例刻意取消能量分解，并称结果不物理；它不能替代 §4.4.2 的有分解剪切作为本项目基准。

## ④ 可以推出什么，以及建议的下一步

[分析判断] 继续剪切方向合理，但应明确选“内部同设置 FEM/PIDL 比较”还是“论文复现”。现有协议属于前者；若目标是后者，需要成组对齐初始场/recovery、两端各自罚项、网络大小/m0/初始化数、积分与载荷表，而非仅将位移方向改为水平。

建议下一份前瞻方案以论文 §4.4.2 为基准：

1. 先固定能量、初始裂缝、尺度、位移边界和载荷列表；对论文明示两端不同的设置逐项记录。未给出的参数保留未确定，不猜测成“论文原值”。
2. 将有效共同范围至 Up=.4 作为目标，在匹配位移比较相场、裂缝转向、位移与能量；另加本项目需要的直接反力。报告 NN 初始种子变化与每个状态的有效性。若 FEM 提前失败，保留有效前缀与失败，不能宣称完成 .4 对照。
3. 将 .4 以上至 .47 作为独立的 NN 延伸问题；该段没有成功 FEM 时，不计算 FEM/PIDL 精度或宣称已验证。增加荷载或换模型都不能默认为复现所需动作。

这比“FEM 必须完整通过至 .46 才有任何有价值比较”的设计更贴近论文。但原有30状态前置条件仍约束已停止的旧运行包；此建议不追溯更改旧标准，不启动新 FEM/PIDL，也不以已观察数据重写旧成功条件。

当前 U=.29 的停机还需独立处理：已有保存量提示交错耦合与残差时序问题，损伤亦有越界；这些发现见 `saved_phase_mechanism_decision_20261021.md`。论文没有证明该具体失败与其 >.4 的问题同源。
