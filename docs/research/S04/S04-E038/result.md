# S04-E038 — 缩小RPROP上限后的无L2卸载结果

目的：判断E035的c1/c40无L2卸载暴涨是否可由数值步长控制抑制。
本轮：max50→0.001，L2=0；两态各从原带L2轨迹的前步网络/历史出发，
其他物理、网格、初始步长、etas、停止设置不变。E035带L2/max50和
无L2/max50是已归档比较组，本轮未重跑。没有全轨迹或c83新运行。

## 判断与L2处置

在这两个局部状态，无L2时只缩小上限，就消除了原先大规模参数暴涨和
孤立额外损伤。因此上限50是本次失稳的重要可干预因素；不能再将
旧结果解释成“断裂物理必须有网络L2”。0.001是预选诊断值，不是最优值。

小上限仍有能量上冲（c1约896倍/c40约18.5倍初态，分别出现在完成1/8次
更新），说明上限并未修复无能量拒绝的RPROP逻辑；c40终点比初态还高
0.096%。早停仍基于相邻loss相对变化，物理净网络梯度约0.246/1.108，
本轮没有新的残差接受阈值或FEM验证，不宣称达到平衡。

第一性原理上，最终物理目标优先不含缺乏物理依据的网络W²；数值稳定
应由步长/能量接受与受约束平衡标准处理。若过渡使用L2，应明确其为
辅助，并验证减小/去除后关键场与演化结果稳定。当前原始W²依赖参数化，
甚至可通过未受罚的TrainableReLU系数作等价缩放，不能当作固定裂纹先验。
详细推导见l2_first_principles.md。正式基线默认设置本轮未改；本结果
支持下一阶段在合格求解器上以无L2为目标，尚不支持全疲劳轨迹有效。
