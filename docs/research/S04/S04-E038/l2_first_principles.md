# 如何处置当前网络L2

目标是使既定相场离散能量在边界条件、damage可行域及历史约束下达到
可信的平衡/局部极小。当前E包含既定GP不可逆软罚；这也不是严格可行域，
本轮不改变该问题。网络是表示场的工具，优化器是求解工具，不能从
某个工具离开L2后失稳反推断裂物理需要网络L2。

实际目标J=log10(E(theta))+lambda*sum(W²)，只罚名字含weight的参数；
偏置和TrainableReLU系数不罚。受罚权重驻点满足
  grad_W E = -2*lambda*ln(10)*E*W
而非物理目标grad_W E=0。log10(E)单独是单调变换，但加上L2后一般
改变极小点。1e-5是系数，原c1卸载终点L2值约0.022，不能只看系数。

参数范数依赖表示。source/network.py的TrainableReLU为ReLU(coeff*x)。
对任一层c>0，把该层W、b同时乘c，把未受罚coeff除c，激活输出严格
不变，而该层W²变为c²倍。它说明当前惩罚并非一个确定的场/裂纹先验，
并有未受罚参数的缩放自由度。此代数例子不是旧暴涨已被测定的机制，
也不意味着浮点、有限迭代实际会沿这条精确等价路径运行。

因此合理分工：
1. 先用数值方法控制更新，保留共同物理能量/场与平衡质量的评价。
   本轮cap0.001只是一次机制干预；RPROP仍可累计漂移、接受上升、过早停。
   单个坐标cap也不限制整网范数步长或场变化，不保证能量下降。
2. 正式物理求解优先以lambda=0为目标，前提是求解器能稳定达到可信
   的受约束状态；若L2作为过渡稳定项，必须明确报告，并验证随其减小
   关键场/能量/演化事件趋稳。不能把一次局部小差异推广成整条疲劳轨迹。
3. 只有明确的反问题先验或表示选择需求才把正则留在最终目标；说明
   正则对象、尺度和参数化理由，并展示敏感性。原始网络W²缺少此物理依据。
   不能在本轮看到结果后再调lambda或上限直到图好看。
4. U0卸载弹性驱动为0，额外损伤仍有Ed成本，但现有不可逆软罚允许轻微
   恢复与有限误差，不宜武断要求所有节点严格d=h。应查看实际能量、
   约束/残差及新增damage，而非只凭范数或迭代损失变化。

当前正式默认值暂不改动；E038只比较两原始带L2轨迹起点的局部状态。
如何采纳取决于实际新结果，不能先将“数值稳定”写成“物理正确”。
