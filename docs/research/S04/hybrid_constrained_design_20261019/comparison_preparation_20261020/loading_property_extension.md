# 要补哪些FEM数据：载荷路径和材料轴

2026-10-20；仅设计，未修改原3600步协议、未实现多材料runner、未求解/训练。本表的变化量是计算方法的探索范围，不代表任何实际材料的不确定区间或实验测量范围。

## 第一性原理的选择

原目标是相同质量下加速当前受约束数值模型；不同幅值已经在第一版中。若要跨材料/路径surrogate，确实需要额外的完整FEM轨迹，并且标签必须来自同一新节点约束/历史合同，不能混入旧未收敛有限罚结果。

设L为固定试件长度、U为位移幅值。在无体力/外牵引、固定nu及边界形状的线弹性分裂模型中，对固定d的平衡，u随U缩放，ψ随E U²/L²缩放。由当前能量/疲劳式，可辨的无量纲组合包括

$$\Pi_G=\frac{E U^2\ell}{G_c L^2},\qquad
\Pi_A=\frac{E U^2}{\alpha_T L^2},\qquad \ell/L,\ \nu.$$

这是本模型齐次性的分析推论，不是经过新求解验证的等价性。相同EU²可以在某些同路径条件下产生重复的驱动力尺度；反力仍按E/U相应缩放，非零牵引、混合边界、历史初态或不同长度尺度会破坏简单关系。因此优先只变E可能只是重复已有幅值轴，不应首先铺E×U全因子。

更有判别力的轴：

- **变幅顺序**：在相同材料和几何下交替载荷幅值，检验A/r/f对先后历史的依赖。仍用五子步、相同位移方向和零位移卸载；不引入后端不支持的力控制/ModeII/非零载荷比。
- **Gc**：改变断裂阻力相对弹性/疲劳尺度；固定ell与网格，以免同时改变裂纹分辨率。
- **alpha_T**：改变疲劳退化启动尺度，检验f<1反馈而非只看早期弹性。
- **ell或nu**：后续独立轴。改变ell必须重新核查h/ell与参考离散误差，不能当前同网格无审查照搬；它们不在下方第一份扩展候选中。

## 一份有界扩展候选矩阵

全部固定E=1、nu=.3、ell=.01、p=2、thickness=1、当前mesh及硬预裂纹。每条轨迹120完整周期/600物理子步，保留全部加载/卸载和GP状态；强求解器不变。幅值系数乘原五子步加载数组，不把cycle序号当充分状态。

| 角色/新case | 幅值系数 | Gc | alpha_T | 数量/用途 |
|---|---|---|---|---|
| 已有A训练候选（条件复用） | .8、1.2 | .01 | .5 | 2×600；只有原A实际完成且质量合格，才可作为扩展development标签 |
| 已有A验证候选（条件复用） | 1.0 | .01 | .5 | 1×600；已暴露/已选模，不再叫新盲测试 |

| test_Gc | 1.0 | .011 | .5 | 新物理配置；reference/classical/hybrid各600 |
| test_alpha | 1.0 | .01 | .45 | 新物理配置；三初猜臂各600 |

新增标签5×600=3000子步，三个测试配置×三臂×600=5400，共**8400新增数值子步**。另需1次重新训练的材料族模型；不能直接用A的单physics冻结模型加载新材料，也不能把A的训练成本或已见测试当成零费用的新盲证据。该矩阵只检验所列插值与交替顺序，不支持跨几何/ell/nu/任意随机载荷，也不检验Gc与alpha_T的联合盲迁移。

这些数据是更宽泛目标的必要准备，不是保证足够训练数据的样本量结论；若某轨迹在120周期内没有f<1或裂纹增长，则该配置不能提供对应机制的验证。首次失败仍终止，不为凑齐表格自动增加周期或扫参数。未来实际启动前要把coverage/stop和完整比较问题一起前瞻冻结。

## 实现和预算含义

目前只实现单一physics身份的严格准入。多材料扩展须明确family_id及允许material集合、保留每条state0/backend physics_id、核查材料随图特征输入及train-only归一化/尺度、每测试配置同材料reference、数值残差尺度与无泄漏分组。不能删除physics_id检查来“支持泛化”。

若**仅用于估算准备规模**，机械沿原每600步20hosth的阶段上限、hybrid每600步6GPUh、一次fit6GPUh：5标签轨迹100hosth；6个reference/classical轨迹120hosth；3个hybrid18GPUh；fit6GPUh；共享replay/analysis暂列4hosth，phase总上限248hosth，GPU24h；16核分配上界3968coreh（仅按248h计算）。至少还需以实际A的IO/输出量核对存储和预留总控制费用，故这些**不是可执行总预算或运行审批请求**。如以后采用此完整扩展，还必须单独做≥8GPUh容量/预算检查及累计探索24GPUh的方向复核；不能从原12GPUh余额里自动执行。

推荐次序：现在把A完整比较准备和独立审核完成；其合格轨迹供给与真实成本出现后，按上述有界矩阵形成正式B预算/运行卡再选。这样保留用户提出的跨loading/property目标，也不会在teacher成本未解决时盲目扩成参数网格。
