## 4. 新发现：持续Anderson实现有历史误清空

冻结实现search在alpha=1仍计算base+(target-base)，随后用np.array_equal(ordinary.d,target)决定add或清空。即使都是合格原bounds的QP全步，减加也未必逐位还原target。事件证明outer2–6普通候选均alpha1/kept；outer5仍insufficient_history，outer6 proposed depth1。两轮间无其他clear，因此outer5/6各add一次，outer5前长度必须0，即outer4走了bitwise inequality清空；outer2/3至少另有一次。目标本来已投影并设crack=1；source中只有全步重构/再clip可改变该数组。独立复审得出同一控制流结论。

这是真实bookkeeping缺陷；未保存原target/base，不能定位当次误差节点或幅度，也不能声称修它后本次就会通过。后续outer8/9/10的AA被原系数L1保护拒绝（9.884/45.568/46.776>5），属于真实保护，不与误清空混为一谈。本次不能称“持续有界AA已完整验证”。人工检查未覆盖这一浮点路径，旧静态通过记录保留。
