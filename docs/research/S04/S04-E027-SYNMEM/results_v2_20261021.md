**本次最小机制验证完整完成，固定H20主结果为负。** 三个数值配置内的两条合法前史都得到完全相同的当前二值图，经历相同20循环续载后，各配置内两臂的未来二值图仍完全相同。未来稳健差像素为0。没有以短跨度、阈值或连续字段差异替换主目标。

这改变的是此设计的推进依据：已能可靠生成“同一当前数字观测、不同内部状态”，但本组合没有给出固定H20下、跨配置稳健可区分的未来数字几何证据，因此不扩合成库、不开始历史模型训练。它不证明历史普遍无用，也不证明二值几何是完整状态。

用户指定的生产机为陶博GPUServer8 CPU；按物理主机连接，未使用误指向剑桥的本地gpu-server别名。小网格、材料、20循环低/高前史（峰值0.005/0.010）、共同probe、原点相位、20循环共同续载（0.030）、64×64相机及d≥0.5阈值保持原设定。

原v1要求跨三配置共六张当前图全等，已有跨网格8像素差使该必要条件不成立；R001/R002又各遭一次控制扫描故障。这些记录保留于[原结果](results_20261020.md)。在查看原点、尚未计算任何未来时，HQ依据直接人方计算托管权限另行授权[protocol v2](protocol_v2.md)：每个配置内部的low/high当前图严格全等，跨配置差异完整保留；H20未来稳健判据、数值接受与完整状态重放不变。v2是前瞻修订，不能称为完全未见数据的独立复现，不能追溯把v1改写为成功。

## 为什么这个负结果有信息

两臂都实际发生了演化：基础与步长细化每臂新增10个前景像素，空间细化每臂新增12个，无丢失像素。原点六臂f全为1；H20的f最低值已降至0.0377–0.0778，累计A最大值为0.0308–0.0465。因此，不能把负结果解释成没有续载生长或疲劳退化未启动。

隐藏差异也没有消失。H20两臂固定相机采样的连续d最大绝对差：基础0.01149385、空间细化0.01028033、步长细化0.01149406；A/f亦不同。这些是已保存状态的诊断，不是新的主终点，不是A单变量因果证据。共同加载后A的相对差变小，并不足以证明“记忆被冲掉”；H20时连续差没有形成跨越本次二值观测分界的两臂差异，才是可直接核查的事实。

## 对observation → state → evolution → prediction的判断

1. **生成器已能用作受控问题的检验工具。** 合法历史、相同当前数字观测、不同完整状态、共同续载及完整状态重放都已实际建立。这个软件/离散系统能力与物理teacher资格仍是两件事。
2. **状态要由目标未来的信息价值定义。** “内部变量不同”不自动推出“需要历史模型”。本设计对未来二值几何没有形成稳健可分目标；直接扩大样本或训练历史编码器缺少依据。
3. **下一项决定是观测目标与可分辨效应，不是模型结构。** 如继续此机制方向，应另定一个有物理解释和独立测量依据的未来量，并前瞻规定其数值敏感性及最小可分辨差；先判断历史差是否对该量稳定可见，再比较当前强观测/已知加载与历史的增益。连续d图可以帮助提出候选，但不能凭这次输出选阈值或时间窗把本次改成正结果。
4. **真实数据路线保留独立要求。** 本实验没有证明响应历史能恢复状态，没有比较学习模型、没有物理标定或真实道路验证。现有真实数据的加载同步、独立裂缝参考和当前响应强基线仍不可省略。

本次的明确决定是停止扩展这一固定设计；生成器保留为机制检验资产，负结果完整保留。任何新前史/加载/观测/窗口均属于另一个前瞻实验，本次未执行。
