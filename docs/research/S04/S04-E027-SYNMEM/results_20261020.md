# S04-E027-SYNMEM：已执行的部分结果与路线判断

目的：在合法不同前史、固定当前数字观测与共同未来加载之间，检验当前几何是否遗漏影响未来的状态。原协议、0.5阈值、64×64相机和六图全等判据保持原样。

本轮：实际在用户指定的陶博 **GPUServer8 CPU** 执行。R001因存储扫描控制故障中止；获得新的有条件单次恢复授权、精确代码审查与原机零求解恢复核验后，R002原样复用253个接受态步并新增104步，又因递归扫描临时锁目录消失中止。两次错误和审查遗漏均保留，未作第三次运行。

结论：**没有获得“同当前、异历史、同续载而未来不同”的完整证据。已有原点却已经证明：本配置不满足冻结的跨网格当前匹配必要条件。** 不继续旧设计，不将缺失未来记为零差异，不扩大合成库。

基础网格低/高前史的两张当前mask逐像素一致，内部A不同，连续d也有差别（最大差0.00110216）。这验证了此数字观测可以把不同内部状态映射到同一张图；**还不能证明这些隐藏差别对未来有预测价值**。三个已有原点都尚未激活疲劳退化（f全1），不能把A差直接当成未来裂纹差。

同一低载前史的16×16与32×32原点mask有8个不同像素，IoU=0.97419355；这8点全部为粗网格1、细网格0。固定相机连续d差最大0.12372044、对称相对L2差3.8485%，仅为已测试空间敏感性，不是误差上界。所有已有原点的32个预裂锚点均有效。

事后读取已接受的zero-settle state0001：**在任何前史加载之前，粗/细网格已经有完全相同的8个差像素**；各网格从settle到origin的mask自身没有改变。settle时A=0、f=1、u=0。这将该差异定位到本预裂初始化/零载平衡的空间离散与数字观测之间，不能归因于不同前史或累计A。

完整六图匹配程序尚未执行，也未生成result.json；但已有两张合法原点图不相等，足以否定“六张全等”的必要条件。这个逻辑不依赖缺失三张图的取值。共同未来、H5/H10/H20与完整状态未来重放均未执行。

## 对研究路线的影响

1. **保留synthetic作为受控机制工具，但先修复观测实验设计。** 不需要先训练网络；本轮已能区分观测多对一、空间离散敏感性、历史尚未进入退化这三件事。
2. **下一方案将两种要求分别定义。** “同一离散设置内两条历史的当前观测匹配”用于构造历史比较；“同一物理状态的观测随离散细化稳定”用于排除数值伪差。新方案仍需明确二者怎样共同约束结论，不能删除失败条件后继续宣传原方案成功。
3. **先确定有分辨率依据的观测和数值敏感性准则，再看未来。** 不能把刚看到的8像素事后设为容差，也不能挑0.45/0.55阈值挽救此配置。可先用既有zero-settle/原点数据研究固定物理尺度的观测；任何新求解、追加网格或续载都需新方案、审查与运行额度。
4. 更强当前观测（连续损伤代理或共同探测响应）、过去加载强基线、响应历史增益及真实裂缝验证仍是后续不同问题。本轮不支持历史模型优于当前状态模型，也不否定隐藏历史机制。
