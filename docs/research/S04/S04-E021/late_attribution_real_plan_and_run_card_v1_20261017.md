## 3. 冻结指标和数值规则（定义，不是本轮结果）

对81个late周期，m0_i／m1_i为已保存physical-raw MSE，单位为原raw archive units的平方：

```text
D_i = m1_i - m0_i
S_plus  = Σ max(D_i, 0)
S_minus = Σ max(-D_i, 0)        # 改善抵消量，报正数
S_net   = S_plus - S_minus
late_mean_MSE_difference = S_net / 81
tau_i = 1e-10 + 1e-10 * abs(m0_i)
```

D_i不是网络场Delta或PDE residual。late内部等周期用1/81，不能混用原整体三层权重1/(3×81)。
加总对象是MSE差，不能把非线性的RMSE增幅百分数线性分摊到cycle。

| 指标／核对 | 原9984226定义与解释边界 |
|---|---|
| k50（主要定位量） | 按max(D_i,0)降序、同值按cycle升序；达到S_plus一半的最少周期数；同时报k50/81和对应cycle ID。不能称这些周期造成全部净退化 |
| 正／负／净量 | S_plus、S_minus、S_net及S_net/81并列，不省略改善抵消量；与ΣD_i闭合差≤Σtau_i |
| 频率 | n_harm计D_i>tau_i；n_improve计D_i<−tau_i；n_tie计abs(D_i)<=tau_i；总数81，同时报各数/81 |
| 最大正贡献 | 最大正D_i的cycle／数值，沿用原排序并列规则；没有正值则记无，不制造异常cycle |
| 晚期RMSE闭合 | mean(m0)>1e-24；sqrt(mean(m1))/sqrt(mean(m0))与冻结已审比值1.0160831289564436的绝对差≤1e-12，仍先通过verification绑定核对保存参考 |
| 不可识别 | S_plus<=Σtau_i时k50=null，不做贡献比例归一化或分母floor；只报可计算描述及不可识别，停止分支归因 |

tau仅区分数值持平，不是物理容许退化阈值；1e-12是原算术一致性容差，不是可调性能门槛。
沿用稳定加总、分别开方求比值；任何非有限输入／中间量、溢出、负MSE、闭合失败或基线不可识别均停止相应解释，
不裁剪、填补、换容差、删cycle或用fallback救结果。不做p值、独立样本置信区间、参数／阈值／窗口搜索。
