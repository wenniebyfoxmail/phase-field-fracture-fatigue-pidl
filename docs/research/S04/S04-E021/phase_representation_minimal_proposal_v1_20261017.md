## 2. 最小设计问题：先分开“目标”和“表示”

问题仅为：**不改训练物理目标、样本权重和输出规则时，一个显式PINN疲劳状态×raw交互项，
能否让已见U0.11晚期物理raw误差相对同设置的加性基线下降？早期／整体为此付出什么代价？**

阶段的proxy不是FEM event、剩余寿命或按误差符号选出的切点。先不按图中转折点切cycle，
不使用c/event_cycle、终态cycle、FEM场作输入，不新造分段阈值；physical_cycle仍保留在原32维中。
只把输出目标的不同阶段表现当作问题，暂不引入阶段专属损失、权重／Pareto算法、多头NN或多目标投票。
这样一次对照只回答表示增量，避免同时改目标与表示后无法区分来源。

拟新增的唯一无量纲列：

```text
fbar_PIN(c) = current_global_fatigue_f       # 原PIN-only native-area全局特征
q(c)       = 1 - fbar_PIN(c)
u(c,x)     = current_psi_raw_direct         # 原特征中实际存log1p(PIN.raw/r_T)
z(c,x)     = q(c) * u(c,x)
X_candidate = [X_original_32, z]
```

q只称“PINN疲劳状态proxy”，不声称真实物理阶段。全局量仅用同一已准入支撑上的当前PIN值；
r_T为同一训练子集的PIN尺度。无新增外部变量／未来输入／teacher场；不是把FEM标签送入proxy。
新增列与原列一样，只用训练数据求均值／标准差；原32列、h_T/r_T和目标尺度在两臂间相同。
q或z是否有足够变化目前未知，本轮没有查看实际取值。近常量时如实记“proxy未被有效激活”，不换proxy补跑。
原feature标准差<1e-12置1规则仅作数值处理，不能伪造变化或把常量说成阶段辨识。
加入交互不表示原模型绝无阶段适应能力：已有lag／global量、相关性及最终非负映射都可能产生变化。
即使有增益，也可能部分来自增加基函数后有效正则化的改变，不能据此单独认定“阶段机制正确”。
尤其q若近常量，z可能只是原raw特征的近比例副本；这时改善也不构成阶段proxy发挥作用的证据。
先公开这项局限，不为探索试验追加第三对照、proxy搜索或一个新的苛刻否决条件。

## 3. 唯一下一步验证提案（未来另批才可开展）

定位：新探索性开发对照，不是重做ATTR、不是旧E021改分，不是fresh holdout或确认验证。
拟主张仅为C2／synthetic的同状态表示增量，不是C3未来预测、物理teacher或道路应用有效性。
改变表示和当前主要问题后，必须另立新的Experiment／Run，不能当E021旧协议的R002救分。
本轮不占用编号／目录、不创建运行卡／命令或grant。

| 项目 | 拟固定范围 |
|---|---|
| 只选一条开发评价轨迹 | U0.11 C1–C121，早期／中期／晚期沿旧C1–20／C21–40／C41+，不移动窗口 |
| 训练分组 | 仅已见U0.115／U0.12／U0.13的旧准入前缀。U0.11不进入拟合／归一化，但已被用来形成假设，因此评价仍是开发探索，不声称全新外推确认 |
| B32基线 | 同一训练数据重新求一个32维ridge，固定alpha=1、未惩罚截距 |

## 4. 验证不苛求：一个主信号，其他指标作为代价

唯一主量：U0.11固定晚期窗口上，以全部准入单元native-area及等cycle平均，计算两臂最终非负raw输出的
`R_late = sqrt(MSE_late(C33) / MSE_late(B32))`，B32参照为1。基线≤1e-24则不可识别，不加floor。

| 有效输出后的观察 | 探索读法与下一步，不是正式部署结论 |
|---|---|
| R_late < 1−1e-10 | 有方向性增量信号；报告实际幅度与早期／整体代价。很小增益只称弱信号，可提下一小步，不要求一次达到5%／10% |
| 1−1e-10 ≤ R_late ≤ 1+1e-10 | 本设置没有可分辨方向；不把数值持平判整条路线失败，不加试验找过线参数 |
| R_late > 1+1e-10 | 此候选在本次未改善，保留结果，不泛化为“阶段表示无效”或改旧E021结论 |
| proxy近常量／未激活 | 仍保留可算的数值比较，但不将增益解释为阶段proxy起作用；不自动换proxy补跑 |
| 输入／数值无效、主量不可识别、触限或不完整 | 分别报告原因／不可识别／不完整，不当成物理反例，不重试或临时更换候选 |

1e-10只防浮点持平冒充方向，不是实践收益／统计显著性门槛；现无物理不确定度／重复性支持实用幅度要求。
不要求“四幅值全好、每阶段全好、每变量全好”或p值达标。早期及等三strata整体的C33/B32比值、
同次V0背景对照、最小raw／非负性、damage/history一致性、proxy范围／近常量说明全部报告，不做辅助指标投票。
早期小退化**不自动否掉探索信号**，而是标“有增益也有代价”，供人判断下一步是否值得；不隐藏明显代价，
不称可部署或比旧V1全面更好。任何有限但很差的结果不必为“通过”追加调参，完成后直接收尾报告即可。
这里没有授权放松已有边界：原E021的Q／early guard仍原封不动；只是新探索不复用那套全面验收承诺。
