## 4. 预先固定的诊断量（公式，不是本轮计算结果）

对late周期i，令m0_i、m1_i为保存的V0、V1物理尺度MSE，定义：

```text
D_i = m1_i - m0_i
S_plus  = Σ max(D_i, 0)       # 正超额MSE总量
S_minus = Σ max(-D_i, 0)      # 改善抵消量，记正数
S_net   = S_plus - S_minus = Σ D_i
late_mean_MSE_difference = S_net / 81
tau_i = 1e-10 + 1e-10 * abs(m0_i)
```

D_i是两个保存MSE的差，不是网络预测场Delta或PDE residual。
MSE单位记为原raw archive units的平方，不新增未经核对的物理单位。
晚期内部均值用1/81；不能混入原整体目标的1/(3×81)，两种口径不得互换。
这些贡献可加总为MSE差，**不能把1.6083%的非线性RMSE比直接按周期线性拆分**。

**主要定位量k50**：将max(D_i,0)按数值从大到小排序，相同值按cycle升序；
k50为累计达到S_plus一半所需的最少周期数。同时报k50/81及这些cycle ID。
这里的50%只是“解释一半正超额”的定义，不是方法合格线或物理显著性阈值。
不把较小k50解释成这些周期造成了全部净退化，必须同时保留S_minus和S_net。

必要配套描述：

- n_harm：D_i>tau_i；n_improve：D_i<−tau_i；n_tie：abs(D_i)<=tau_i，三者总数必须为81。
- 报各数／81，以及最大正D_i的cycle和数值；不做p值、独立样本置信区间或参数搜索。
- tau沿用原算术量级，只区分数值持平，不代表物理容许退化；不事后换阈值。
- 若S_plus<=Σtau_i，k50记为不可识别，不加分母floor或制造贡献比例；停止分支归因。
- 不用逐cycle相对误差比例做主分析，避免小基线分母放大；不再增加变换尺度指标。
