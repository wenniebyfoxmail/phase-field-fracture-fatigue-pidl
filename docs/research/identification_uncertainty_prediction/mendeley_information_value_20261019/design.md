# Mendeley 发布DIC状态的信息价值：成组探索设计 v0.1

2026-10-19。**准备稿，非已运行结果。** 原owner为[[Dataset archive index]]。Portfolio将识别不确定性→预测列为战略副线，本稿落实其计算探索分支；SCB真实测量参考申请并行，[[SCB 2020 数据申请邮件]]保持原待审版本，未发送。

## 从原目标到这个分支

原问题：独立标定观测UQ是否改善独立未来裂缝参考预测。当前缺独立观测误差轴，因此不把阈值范围称为物理测量概率。单列可计算的问题：**硬识别压缩是否丢失了发布DIC场中可用于预测未来同类观测的信息？** 这是目标上游的表示/观测信息价值，不替代真实裂长、latent damage或现场道路验证。

实测瓶颈不是“没有位移数据”：S02-E006已取得19组、17,925CSV、17,897PT帧；四sheet实际仅两个标签编码。V0/V1候选的稳定性变化不是准确度；人工硬点暂停。复用完整验收、候选与网格/命名问题，不再解压、重提取或复核整个库。

机制：硬端点/标量T(y)可能把驱动未来可观测场所需的弹性背景、局部变化或多种可行位置压掉。比较更丰富的点状态与保留阈值歧义的集合，判断是表示不足、简单噪声正则化，还是特定观测歧义有用。用同一未来场目标，避免各方法换标签。

## 输入与时间/空间接口

实际接口复用`pt_frame_inventory.csv`与`probe_v1_concentration/candidate_trajectories.csv`；原始PT仅在未来获准运行时按已审member/list_index安全加载，形状[1,2,128,128]。不用作者模型、XLSX、Predicted列或原始CSV再造标签。

- 目标为N+H发布PT的两通道网格场。**网格索引上的发布值**可作为可重复对象，不要求先证明CSV→PT物理坐标映射；不能称作同一物理材料点的真实位移/裂长。位移量采用发布单位（来源称mm），空间坐标保持grid index。
- 先用发布stage作为唯一序列索引。历史为[N−20,N−10,N]；H为10与40stage（README名义300/1200cycles），两个等权，不按得分选H；机器cycles/加载相位未完全验证，输出中保留此限定。
- 每组在首个stage确定的5stage步长网格取起点，同一PT chunk内要求整个[N−20,N+40]连续、字段有限、历史点/阈值集合都可得。禁止跨chunk，避免未验证的导出边界；这仍不能证明chunk内物理reference恒定。
- 19组均按同一可用窗口规则纳入，不按作者裂长是否有标签选组。8组CSV头部命名偏移不作为真实循环来修补；对本发布PT索引任务保留标记和分层。E_0Deg_20%_#2只用已取得前缀，缺28帧不补齐；NaN窗口剔除留痕、不补零。
- 每组最多80个起点，按可用起点序列均匀确定，至少6个才能纳入；资格规则和每次排除都写manifest，不偷偷改样本数。选择覆盖发布前/中/后段仅是回顾性探索设计，不向模型提供序列终点、最终寿命或未来信息。早中晚按实际保留stage展示。
- 局部带是既有V1首帧ROI中心±16网格行、全宽，不是独立物理裂纹区；所有方法共用。当前与过去V1参数敏感性可用，未来V1端点不可用，也不作为目标。

明确剩余阻塞：当前没有重新运行manifest准备，因此**实际纳入组/窗口数尚未生成**；PT数值/训练路径尚未做集成运行。若历史共同有效点过少，该组按固定规则报告排除。即使全部可用，也只能回答发布索引上的场延续，不回答物理周期增长。若连PT内部顺序/对象都被后续资料否定，则停本目标；替代仅为已知相隔stage的发布数组条件预测，需改名并注明处理过程混杂，不制造物理标签。

## 同一模型族的一组比较

所有方法读相同三个历史时刻、几何/角度/应力元数据，使用同一个ridge映射与同一alpha网格[0.1,10,1000]。不输入试件重复号或任何未来响应。预测目标为16×16池化未来增量，输出时还原到128×128并加当前原场；所有学习方法共用此输出基底。它降低计算成本，不把粗网格预测冒称原生全场细节。

| 方法 | 具体表示/干预 | 能区分的解释 |
|---|---|---|
| persistence / secant | 原网格保持不变/过去10stage原场差分外推 | 复杂表示是否超出强简单外推 |
| scalar | 各历史时刻V1名义像素span及span² | 硬识别压缩的下界；不换算物理裂长 |
| compact | scalar加全场/局部带两通道均值、标准差 | 少量响应统计是否已经足够 |
| rich | compact加每时刻8×8两通道块均值 | 较丰富点状态是否恢复被压缩的信息 |
| rich_fixed | rich的span变量变为三种固定宽度情景；宽度只用该折训练组现有阈值差中位数 | 是否只是固定扰动/正则化 |
| rich_set | rich的span使用V1的0.8/1/1.25三种阈值情景 | 与具体观测对应的规则歧义是否比固定扰动有用 |

fixed/set使用相同三情景训练与相同预算；每个原案例总权重相同，按组等权。三情景是确定性设计权重，**不是概率**。输出情景最小/最大包络及中点；主评分中点，包络只描述规则敏感性，没有覆盖保证。本稿不实现未经标定的概率分布，也不称其为真实UQ校准。

rich_set并未获得比rich更多原始测量，集合也是同源场的衍生函数。若它有增益，先解释为该规则/有限表示下的歧义编码收益；不能单凭它排除“特征工程/正则化”解释。fixed对照限定其一部分竞争解释，SCB独立资料用于后续检验更强假设。

另算**oracle_output_projection**：用真实未来增量投影到同一16×16输出基底的误差，只作输出表示能力诊断，不参与预测基线胜负，不允许被称作预测。若它本身误差高，则学习方法失败不能被解释为历史没有信息。

## 分组、调参与主criterion

所有19组已在既有工作中开发曝光。外层按发布group留一，不称全新盲测或独立物理资产确认；同代码的所有时间与情景留在同一侧。物理谱系未核实，不给伪精确总体置信区间。

每外层折在其余组内固定取排序后每第四组作内层验证，其余拟合；同一划分用于全部方法，按组等权选alpha，再用全部外层开发组拟合。缩放、固定扰动宽度、特征标准化与参数只来自相应训练组。主图同时展示各组、各horizon，不用单个平均数隐藏逆转。

**唯一主criterion：全场/局部等权的标准化MAE。** 对每通道，尺度s由当前折开发组的未来增量平均绝对幅值估计并固定；下限1e−6仅为数值保护，不是测量误差。L=0.5·mean_full(|预测−发布目标|/s)+0.5·mean_local(|预测−发布目标|/s)。先起点组内平均，再对两个H与组等权平均，越低越好。

同时保存原单位full/local MAE、逐案例值。标准化防止通道尺度差异；50/50空间权重防止背景面积淹没局部变化。主要成组排序包括scalar→compact→rich与rich→fixed/set，强简单P/S必须同时显示。样本数与误差波动决定可解释范围，不先捏造改善百分比为成功门；任何微小或仅单组改进保留为局部进展，不能支撑一般性结论。

本分支使用集合，因此不以CRPS假装概率质量；原SCB方案仍保留概率预测CRPS，用于以后有真实误差依据的distribution比较。

## 结果选择路线

| 观察到的结果 | 选择 |
|---|---|
| rich明显优于标量/compact与P/S，但set无额外收益 | 主要问题是状态压缩，优先表示；删去不必要UQ包装 |
| set比rich与fixed均有可重复的组/时域收益 | 保留该阈值观测通道的信息假设；待独立资料再谈物理概率校准，不提前宣称原主问题成立 |
| fixed≈set且二者优于rich | 优先简单扰动/正则化解释；不宣称结构化误差信息不可替代 |
| 各学习法均不胜secant，而oracle输出基底误差低 | 回到可观测状态/驱动/时间假设，不扫新架构；保留局部有用阶段 |
| oracle基底局部误差高 | 输出基底是竞争瓶颈，不能据此否定历史信息；只针对该表示限制改设计 |
| 仅全场好、局部差或长H崩溃 | 不称整体裂缝相关预测成功，按局部/时域瓶颈处理 |
| 可用组/顺序不足或reference变化无法解释 | 报精确文件/stage缺口，保留发布过程预测的窄解释，或停止该目标 |

## 实现、预算与执行边界

`runner.py`支持`--prepare`（仅既有元数据，零tensor/fit）和单独授权的`--run`。安全加载`torch.load(weights_only=True)`，输入只读，8个PT文件LRU缓存；数据清单/候选表SHA固定，实际读取PT哈希随run记录。新输出目录、不覆盖、不自动重试。代码包及资源申请见EXECUTION_REQUEST.md。

拟议producer为Taobo单CPU线程，4h墙钟、0GPU、输出8GiB、内存上限8GiB；输入复用既有解压PT约2.35GB和既有元数据，不搬运17.6GB CSV。当前未SSH、未传输、未启动。实际环境/存储/来源映射、输入转移校验和确切命令须纳入最终审核；任何source/config改变都更新包身份。

本轮仅通过四项人工构造元数据的接口单测：前缀与准确H、未来scalar不被使用、非有限目标共同排除、重复身份拒绝。它们不是PT集成验证、模型成功或科学结果；未读新tensor、未fit、未执行真实prepare或任何producer run。

批准运行后必需产物：manifest及排除清单、确切代码/输入/环境收据、各fold/horizon/方法的粗增量/情景包络与重建参数、逐例full/local/主评分、全部发布组的代表场预测/误差图（每组固定取中间保留起点，不挑好例）、逐组全场/局部评分图、路线结论。无图或部分run不得称完整交付。
