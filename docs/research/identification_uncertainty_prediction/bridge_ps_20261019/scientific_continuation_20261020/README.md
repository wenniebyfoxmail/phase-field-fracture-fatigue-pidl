## 2. 当前接口到底观测了什么

观测生成可写为 `y_n=O(x_n,b_n,phase_n,reference,camera)+epsilon_n`，未来为 `x_(n+H)=F_H(x_n,b_future)`。内部状态x、加载b、参考/相机均可能改变位移；没有加载/参考同步，不能把响应变化唯一归给损伤记忆。

代码中的c并非“完全无历史”：C_RAW20维=12维共同前缀（组元数据、H、三时刻span及平方、起点发布索引及平方）+当前双通道全域/固定带均值与标准差8维。H_INNOV额外使用过去两时刻的6维相对统计差，共12维：全域std、局部均值减全域均值、局部std；`e=h-m(c)`中m只在相应训练折估计。**不是空间分辨的裂尖历史，也不是已测载荷/真实速度。** 过去span已在各臂共享，当前完整128×128场仅作共同输出锚点。

它能提供：给定这个压缩当前接口后，与未来发布增量有用的最近变化代理；可能含加载相位、顺应性、局部化趋势或处理方式的混合信息。它不能唯一识别d/H/材料参数、载荷与损伤的分别贡献、物理Markov状态、独立裂尖/深度或R/Q分离。H是发布步，不是已校准cycle或秒。

更严格地说，固定m后`(c,h) <-> (c,h-m(c))`可逆，残差化**不创造信息**，会改变有限ridge的惩罚几何。H_RAW_PULLBACK已排除“同一原36维函数换坐标就产生新信息”的解释；但它不是对H_INNOV32维与同信息32维原坐标的全部惩罚效应作因果分离。H_REL还删除当前整体均值，不能单凭H_INNOV胜H_REL就把差全算给历史。Donor同32维、同当前c，支持“对应自身历史比这一个替换规则更有用”，仍不是条件独立定理/精确随机化检验。

输出增量只含16×16块值，重复成128×128；每8×8块内预测增量为常数，不能生成任意新细尺度增量。共用当前细节不等于学到了未来细节；不把pool(target)的误差叫MAE理论下界。
