## 3. 最小分解：先区分两个向量，不给它们硬贴物理标签

记冻结 secant 预测为 S，力学预测为 M_k（old/proxy/intact），已有目标为 T。
P 是 R003 全部646点、同一训练面积权重下的全局平面刚体补空间投影。
全程固定P；不按区域、分量、模型改变其子空间，不做逐侧补偿。

定义：

```
e_s = P(S - T)                  # secant—目标残差
c_k = P(M_k - S)                # 力学—secant偏离，不称作已验证的物理修正
e_k = P(M_k - T) = e_s + c_k
```

同时只做冻结构造的代数核对，不重新生成预测：

```
S   = alpha * train_v
M_k = alpha * sampled_k
c_k = alpha * P(sampled_k - train_v)  # 同一646点子集与P
```

train_v 与 sampled_k 由原有R001/R002资产按相同ID顺序取子集。
这个恒等式说明，三组力学臂和secant的差别是同载荷比例放大的训练侧
空间拟合偏离；所有臂采用相同线性载荷外推，并没有额外的高载演化方程。
它不说明secant无噪声，也不证明差别完全来自某一边界或材料因素。
原prepare/solve/外推代码均不执行；只对已保存数组核对恒等式。

## 4. 主诊断量保持 MAE；平方量只解释向量相互作用

令 W=sum_i w_i。每点的精确 MAE 差额：

```
d_ki = ||e_si + c_ki||_2 - ||e_si||_2             [mm]
G_k  = sum_i w_i*d_ki / W = L_k - L_secant       [mm]
```

G正表示该冻结力学臂较secant更差，负表示更好；它只复现已有排名，
不是新主指标。还应报告 L_secant 与 sum_i w_i*||c_ki||/W，
以免将secant当作无误差参考。
禁止把两个范数相加当作 MAE 的可加分解。

为解释方向/幅值相互作用，另报平方范数恒等式（单位mm²）：

```
E_s = sum_i w_i*||e_si||² / W
E_k = sum_i w_i*||e_si + c_ki||² / W
C_k = sum_i w_i*||c_ki||² / W
I_k = 2*sum_i w_i*(e_si dot c_ki) / W
E_k - E_s = C_k + I_k
```

C非负是偏离的平方幅值，不能单独称为物理代价；I负表示在此度量下部分
抵消secant残差，I正表示强化。若平方量与MAE描述不同，分别报告，不用MSE
改写E016的MAE结论。没有独立噪声/因果分解；I不是独立随机误差的协方差。
禁止计算目标最优混合系数、oracle缩放或据此提出已调好的新预测。

## 5. 仅两个固定空间区域，所有点保留

使用训练规则已有的b=3.6mm定义：

- B：abs(stage13_y)<=3.6mm；
- O：abs(stage13_y)>3.6mm。

不随stage15残差改变界线，不按误差大小选点，不扫描不同宽度/端点。
这是训练开口条带内/外，不叫真实裂缝过程区或可靠/不可靠观测分区。
每区报告点数、权重面积与区域条件均值，但用同一个全场P投影后再聚合。
若区域为空，条件均值标记不可用，不修改界线或补点。

可加贡献均保持全局分母W：

```
G_kr = sum_(i in r) w_i*d_ki / W
C_kr = sum_(i in r) w_i*||c_ki||² / W
I_kr = 2*sum_(i in r) w_i*(e_si dot c_ki) / W
G_k = G_kB + G_kO;  C_k = C_kB + C_kO;  I_k = I_kB + I_kO
```

区域条件均值需明确除以W_r，不能将两个条件均值直接相加，也不把
空间分区当成独立重复。所有机械臂都报告，不选“最好解释”的单臂。

## 6. 允许的解释与下一步分支

| 可见现象 | 允许推论 | 不能据此推出 / 最小下一步 |
|---|---|---|
| c_k 与 e_s 同向强化，净差额为正 | 已有模型偏离在该度量下增加误差 | 不能指定为材料/边界错误；另审训练侧空间表示/边界一致性诊断 |
| I_k负但平方差仍为正 | 有部分抵消，但平方幅值超过抵消 | 不能据此调混合系数；先报告MAE是否同方向，再冻结新证据的诊断 |
| 正差额主要来自B或O | 差距集中于所定义条带 | 不能把B等同断裂机制、O等同边界因果；据此选择一项独立空间证据 |

| 代数/身份/数值核对不一致 | 该诊断暂不可解释 | 保留现场，停止，不自动改旧结果或重跑 |
