## 2. 只选一个干预：投影基底先回到Q空间，再正交化

沿用原定义与求值方式：Qx=x−H(Hᵀx)，输入H、y和原保留基底Lr不变。
未来获批的合成测试中，固定做：

```
B = Q Lr                         # 恰好一次，不迭代投Q
B = U T                          # 一次薄QR；同时调整U/T符号使T对角为正
p_new = U (Uᵀ y)
r_new = p_new − y
```

只有U/T和新p/r进入新分支；不覆盖原Lr、原p/r或原失败状态。不对p_new、
r_new追加Q，不改变H或y，不换精度、SVD driver、截止值或保留模式数。

精确算术且H正交时，U张成的是 **span(Q Lr)**。这与原span(Lr)可能不同，
并非声称保留原近似子空间一字不变；保留的是原模式选择，并将其像限制
回刚体商空间。必须显式报告这个目标变更。

为什么不是只做p_new=Qp_old：QLr通常不再正交，直接Qp_old一般不是
span(QLr)上的正交投影。薄QR是为了恢复正交投影定义，而非只让Qr检查
看起来通过。不使用正规方程或显式Gram逆。

有限精度H不是严格正交，QR也有舍入；上式不是Q一致性必然通过的保证。
原容差下仍需独立验证；不通过就停止，不补第二遍Q或换精度自动重试。

### 保留秩的保护，不靠丢列消除问题

合成固定5个保留模式，不重新选秩、不重算奇异值。薄QR必须返回同样5列，
验证UᵀU=I与UT=B，并作一个额外的充分安全检查：符号规范化后的
eta=||I−T||∞须≤1/2。精确算术下此界给出T可逆及cond∞(T)≤3，故投Q
没有以近坍缩换取通过；实际重构/正交检查仍执行。
这是新增的拒绝保护，不替换或放宽任何原阈值；不满足时报告本修复不适用，
禁止降秩、删弱模态或改变1/2继续。未来真实扩展需单独审查适用性。

新U/T不是原A的一组新SVD因子，原s/V不能与U拼接后宣称重构原A。
C2将有意去除注入A的刚体分量，针对的是其商空间像；C3不等于测量到
真实SVD误差。两例即使修好后的p相同，也必须继续保留不同来源标签。

## 3. 下一项最小检验：只用C1–C3解析定义，零次SVD

证据域synthetic；claim class为C1数值可采信性，不是当前状态反演C2。
每例是算法控制，不是独立试件。没有预测原点、时间跨度或泛化结论。

未来若获批实现/执行，只从受审源码中的人工Hadamard16常量构造C1–C3，
不读原report、真实648点或任何归档数组；不加入C0，不重建真实A。
固定H、y、s、t、c、a、五列选择及原乘法路径，不能拟合真实错误幅度。
人工输入的解析clean基底只用于独立参考，不替换候选算法的输入Lr。

| 固定用例 | 原路径比较对象 | 修复候选要回答的问题 |
|---|---|---|
| C1 干净解析基线 | 原p/r及原Q检查 | 是否保持已正确的投影，而非无故改变基线 |
| C2 人工A输入泄漏 | 原负控及输入来源标签 | 对其商空间像能否得到正确投影，而非声称还原原A |
| C3 人工近似因子泄漏 | 原负控及因子来源标签 | 对同样受污染基底能否恢复Q一致投影，而不反推真实根因 |

唯一主要标准：三例新投影均与预先已知的解析Q空间正交投影一致，使用
原位移向量容差；C1原结果保持，C2/C3原路径负控状态照实保留。
这里已知的干净五列记L0，参考为p*=L0(L0ᵀy)、r*=p*−y，不使用数值SVD。
这是对这些固定构造的参考，不主张对未知真实A存在同样解析答案。

以下检查是使“正确投影”可解释的必要条件，不以它们择优或挽救主标准：

1. H/y输入一致，输入y原Q检查通过；不重新补偿目标。
2. 保留5列、UT=B、UᵀU=I、上述eta保护、QU=U通过；不隐藏秩变化。
3. 新p/r的Q检查、Uᵀr_new=0、p_new−y=r_new及Pythagoras恒等式通过。
   平方分解以预先固定的五个b_j=2^-8 L0[:,j]为合成模型向量；先核验
   b_j在U像内，再核验||b_j−y||²=||r_new||²+||b_j−p_new||²。
   它们不是四组真实冻结预测，不能代替真实模型像空间可行性检查。
4. 独立只读算术验收保留producer路径与参考路径标注；跨路径差异不自动
   命名为原report错误，不修改原D01算术验收语义。

全部原比较形式保持abs(x−ref)≤atol+1e-12*abs(ref)：矩阵/无量纲量
atol=1e-12，位移向量1e-15 mm，平方量1e-18 mm²。原tau=1e-12*smax、
截止保护区间及分类T都不改；本分支不生成真实floor/gap分类。
Q向量检查不能靠矩阵容差替代，不能用“降低ratio”代替原标准。

预期是C1不变、C2/C3新分支改善至正确投影，**目前没有计算，尚未验证**。
若新分支Q检查通过但参考不一致、秩保护或正交/分解不通过，仍不能称修复
成立；这会选择继续检查投影定义/秩保护，而不是调物理参数。

## 4. 如何帮助推进真实DIC反演，而不是无限停在算术检查

这项修复的用途是恢复一个可解释的比较工具：在固定采样/权重/边界下，
观测能否由当前运动学空间表示？若表示上限很低而平衡模型残差仍大，
再讨论模型/边界/先验；若上限本身有限，优先处理表示或观测问题。
这种分解是条件性的数值诊断，不把任一残差直接归因为噪声、边界或材料。

桥接顺序：

1. **本方案的合成验证**：证明候选能处理已知Q外泄漏，且不靠改目标、
   删模式或放宽阈值。通过只取得合成数值修复证据。
2. **另批训练侧真实复核**：保持cycle292018.5、stage13/14、原网格/边界、
   648点及原权重/四组冻结预测不变；在独立新分支检查同一Q的观测、
   基底、候选响应可行性与残差分解。真实A/Lr未保存，不能现在用零SVD
   “修好旧E019”；是否重新构造/做一次新SVD、资源预算与中间量保存，
   必须另立方案、审查并取得执行授权。当前不读取这些真实输入。
3. **再决定最小反演**：若真实数值一致性通过，才用同一加权/刚体处理的
   观测残差和响应敏感度审查低维当前损伤参数的可辨识性。观测输入是
   已授权训练DIC、坐标/权重、边界与固定先验；模型给出位移响应；拟合
   的才是条件于这些假设的当前损伤参数，不是从投影p直接得到相场。
   运动学自由度不是可唯一反演的材料参数；本轮不加q、不改现有q=0结果。

对位移控制问题，稳定的Q空间损失也不能凭空辨识绝对E、Gc、长度尺度、
   疲劳参数或真实完整损伤场；仍需独立力学信息和敏感性证据。对未来
   cycle的预测还需要状态演化规律，不能把当前静态拟合当未来预测。

stage15已用于E016-R003评价，不再作为未见的调参/新验证数据；当前也
不读取其响应、不读取新留出。未来验证信息集与许可另行定义。
