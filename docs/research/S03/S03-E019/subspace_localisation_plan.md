## 4. 分层账本：不靠总误差猜根因

后续固定用Decimal.from_float精确转换输入float，再以80位计算高精度参考。
这不是无限精度真值，也不重新求任何分解；同时用独立math.fsum交叉核对。
以下各式的精确代数意义与实际有限精度评估误差分别记录。

### A层：H本身误差与quotient求值误差分开

令C=D S_F、G=HᵀH、A_ref=(I−HHᵀ)C（同一float输入的高精度参考），
A_fl为原multiply/quotient的float结果，delta_A=A_fl−A_ref。

```
Hᵀ A_ref = (I−G) Hᵀ C
Hᵀ A_fl  = (I−G) Hᵀ C + Hᵀ delta_A
```

分别报告G−I、输入构造项和求值项，不把H非精确正交全部命名为SVD误差。
矩阵算子是无量纲量，不使用mm容差去判这层。

### 保留子空间层：小奇异值可放大两种不同来源

合成已知因子L、V、s，预先固定保留5列，无数值分解。定义
E=A_fl V−L diag(s)，则逐列有：

```
Hᵀ L = (Hᵀ A_fl V−Hᵀ E) diag(1/s)
```

报告输入A的泄漏项、因子重构残差项及1/s放大量。该式可说明矩阵重构
容差通过不必保证弱模态的Q空间误差通过；不引用/推测真实未知Lr。
同一泄漏既可能来自输入扰动，也可能来自近似因子误差，不能从p/r唯一反推。

### p层：子空间已有泄漏与乘法/减法新舍入分开

令p_ref=L(Lᵀy)为相同输入的高精度参考，p_fl为原multiply两次求值，
delta_p=p_fl−p_ref；r_fl=float(p_fl−y)，delta_r=r_fl−(p_fl−y)_ref。

```
Hᵀ p_fl = (Hᵀ L)(Lᵀy) + Hᵀ delta_p
Hᵀ r_fl = Hᵀ p_fl−Hᵀy + Hᵀ delta_r
```

按项报告，禁止以最后总误差小/大就单独认定前一层有错；不把p_ref写回
原产物或当作修好的E019投影。所有这里的新向量仅属于纯合成用例。

## 5. 四个固定合成用例（拟定，当前不运行）

不使用随机数、真实残差、case搜索、秩扫描、参数扫描或匹配真实错误幅值。

### C0 — 原A构造函数的人工空间输入，无分解

人工xy固定为8对mm坐标：(-13.05,-4.95)、(-8.55,-2.25)、(-4.05,2.25)、
(-0.45,4.95)、(0.45,-4.95)、(4.05,-2.25)、(8.55,2.25)、(13.05,4.95)。
正权重为[1,2,3,4,5,6,7,8]。仅用常量41×21网格/边界、原sampling和
rigid_basis取得16×1482合成C与16×3合成H（一次薄QR，非SVD）。
按第4节分解A层；没有y/p/r，也不做谱/秩或投影。此例只检查A构造算术，
不证明真实648点A的泄漏量，也不检验网格/边界的物理正确性。

### C1 — 解析干净基线

Sylvester Hadamard矩阵K16，归一化O=K16/4（二进制精确常量）。
H=O[:,0:3]，L=O[:,3:8]，V=O[:,8:13]，g=O[:,13]；均为预定列，不经QR/SVD。
s=[1,2^-4,2^-12,2^-24,2^-32]，A0=L diag(s) Vᵀ；
y=2^-8*(L[:,0]+L[:,4])+2^-12*g（标注合成mm）。
原tau=1e-12*smax，5个已知非零s均高于10tau；零模态解析已知，不数值找秩。
预期HᵀA0、HᵀL及p/r泄漏均为0（独立算术检查仍保留原容差）。

### C2 — 已知A输入扰动，解析因子与其一致

固定t=2^-20，c=(1−t²)/(1+t²)、a=2t/(1+t²)。把L第5列替换为
c*L[:,4]+a*H[:,1]形成L_t；其他列、s、V、y都不变。
A_t=L_t diag(s) Vᵀ；输入A_t和解析因子L_t一致。仅弱模态离开Q空间，
输入扰动规模受s第5项缩小；高精度参考保留float(c,a)本身的舍入误差。
此为人为输入泄漏机制，不声称来自本机A构造或原gesvd。

### C3 — A干净，近似保留因子带同样扰动

输入A0不变，但使用同一个L_t、s、V作为人为近似分解。E=A0 V−L_t diag(s)
非零，按第4节拆出因子重构项；它可很小而子空间泄漏不小。
C2/C3使用同一个L_t和y，投影相同而来源标签不同：这是不可反推根因的
明确对照。这里没有调用SVD，不能将人为因子扰动命名为实测SVD求解器误差。

C1–C3均比较原multiply计算p/r和高精度参考；不额外对p施Q、不修正因子。
仅这4例，不见结果后再增加工况、换t/s或补充精度来寻求通过。
