## 3. 选定的最小处理：参考乘积的精确定义求值

仅允许用于上表五处“原奇异因子乘s”的诊断参考。不是A/H/候选投影运算，
不接管任意点积、权重、平方、QR/SVD内部或其他浮点异常。

目标是对实际输入的每对有限binary64 x,t，给出IEEE binary64逐渐下溢、
round-to-nearest/ties-to-even模型下的`RN64(x*t)`，不把理想十进制重新生成输入。
仍返回同形状float64参考；不是全流程高精度，也不把误差预算加到容差里。

拟实现（未来另批；本轮不实现）：

1. 先核dtype/shape/有限、位序与所需浮点模型。不支持则拒绝，不静默转换
   或切另一算法。±0乘有限数按符号异或构造正确零位型。
2. 非零输入用frexp/位型取得指数，不先乘。若frexp指数和≥−1020，
   产品绝对值≥2^-1022，走一次原NumPy乘法，保留overflow/invalid首停。
3. 指数和≤−1021的保守小乘积分支，直接解码原位型为
   `x=(-1)^sx Mx 2^ex`、`t=(-1)^st Mt 2^et`；正规数
   `M=2^52+fraction, e=E−1075`，次正规`M=fraction,e=−1074`。
   整数P=Mx*Mt，e=ex+et；不执行危险的浮点乘法。
4. 以量子2^-1074求P*2^(e+1074)最近偶整数N，使用整数商/余数处理
   小于半格、正中间和大于半格。通过整数位型封装输出，不用浮点ldexp
   或`float(product)`隐藏异常。N=0保留有符号零；N<2^52为次正规；
   N≥2^52须处理到最小正规及其上方的边界进位，不能一概打包成次正规。
   本保守分支产品小于2^-1021，需支持N到2^53的舍入进位。
5. 正常/整数分支预先选定，各操作数只计算一次，不捕获一次下溢后重试。
   零值只来自正确舍入，不能据数值大小手动删项。任何位型/边界证书不符即停。

每项小乘积保存原索引/输入位型/输出位型/舍入方向和整数商余数证书；
汇总数量与变零数量。误差界用符号/整数表示，例如半个最小次正规量子
`2^-1075`，不能转成float0后谎称无误差。该界是舍入说明，不是额外容差。
正常项全量保留原结果。未来同尺寸成本、证书大小及预算须实测，不预判能完成。

## 4. 比较必须保留原不等式，不用ratio替代

规范判据始终为`abs(a-ref) <= atol + 1e-12*abs(ref)`，逐分量且全量检查；
先核shape/finite。浮点模型明确为各步binary64 RN64，不能偷偷变成不同
精度的阈值。新求值只避免非必要的危险中间量：

- d=abs(RN64(a-ref))仍在原异常策略下计算；有overflow等直接停。
- 对abs(ref)<2^-900，预先证明RN64(atol+RN64(rtol*abs(ref)))恰为atol，
  因rtol<1，而三个原atol的最小半ULP不小于2^-113，tiny相对项无法改变
  最后舍入。该分支直接用同一atol，不先算tiny乘法。
- 对abs(ref)≥2^-900，rtol>2^-40，产品≥2^-940，故相对项乘法不是次正规；
  用原float64乘法/加法。任何实际异常仍停。2^-900仅为算术派发界，
  不作为新精度/物理门槛，不改变任一分量的限值。
- 用d<=denom做主判断，不为作决定额外除法。Q的legacy和独立参考通过
  状态也按同一不等式；不改变“legacy可通过或不通过”的诊断角色。

删除除法的通过状态等价性必须限定前提：d和denom已按上述步骤舍入为
非负有限binary64 d及正有限binary64 denom，除法模型正确最近偶舍入。
若d<=denom，RN64(d/denom)<=1。若正规denom位于[2^e,2^(e+1))且
d>denom，下一个更大binary64 d至少增加2^(e−52)，所以
`(d−denom)/denom > 2^-53`，严格超过1向上相邻数的半ULP；次正规denom
的相对最小间隔更大。因此不存在可达的“d>denom但RN64(d/denom)=1”
区间，二者通过状态等价；不应新增这样的负控或未决门槛。
前提不满足按原输入/模型检查拒绝。直接不等式避免非必需除法的下溢/
overflow求值，不豁免任何实际出现的异常，也不追认B001失败或改变原容差。

`close`当前返回的max ratio未被调用方消费；未来只保存最大绝对差、对应
限值/索引和通过状态。legacy原Q_ratio字段若保留须另用精确有理数表示
（字符串/整数），不为显示重新引入浮点除法。新schema另审，旧报告不改。
浮点ratio数值不作为新增检查，也不以“ratio下降”判修复成功。

## 5. 独立参考与只用人工输入的最小验证设计

当前不写/运行测试。未来先批准一个新tiny合成单元包，0实际QR/SVD、
0真实/归档数组读取、单线程CPU/60秒。只从声明源码/位型造数，不能重造

候选用位型/整数舍入；独立参考用从原float精确导入的Fraction有理数，
核输出浮点值的精确有理数是否位于最近格点及ties-even条件。不得调用
候选打包/舍入函数或以NumPy危险乘法当真值；80位Decimal不冒充任意
次正规边界的严格精确参考。±0符号另核。普通区间另核原路径同值。

| 人工类别 | 必须核验的行为 |
|---|---|
| 正规、零及正负号 | 原结果/逐位相同；符号零正确，不截断普通值 |
| 精确次正规 | 保留非零，不擅自flush-to-zero |
| q=2^-1074，输入对q×0.5、(3q)×0.5 | 正中间最近偶：0与2q；负数保留相应符号；不可把已舍入的q/2当输入 |
| 半格上下邻域 | 下/上舍入及ties-even，不靠宽容差“差不多” |
| 最大次正规/最小正规及保守分支上沿 | 进位/指数/尾数完整，不丢最小正规以上结果 |
| ±2^-900派发边界及三个原atol | 与独立逐步RN参考同一分量判据 |
| 恰好限值及可达相邻浮点外侧 | 该过则过、该停则停；对有限正分母核直接不等式与比值通过状态等价，不制造不可达负控 |
| NaN/Inf、overflow、错误dtype/shape/证书 | 首个异常或不符停止，不产生成功收据 |
| 未覆盖位置的下溢与logging WARNING | 仍首停，不因本辅助求值器获得豁免 |
| 参考分歧/中途预算耗尽/输入位型变动 | 专属未决或预算失败，禁止自动替换候选/扩时 |

旧原始NumPy直接乘法触发下溢只可作为预先明示的人工负控，在test断言
内捕获且不把该结果作为候选输出；候选路径不允许任何下溢或警告豁免。
每组须覆盖正负、精确/非精确、正常/次正规和临界进位，不在本稿凭空
声称已实现具体测试数、已通过或底层硬件一定支持所需模型。
所有人工操作数本身必须为可表示binary64；半格/不可表示目标只作为精确
参考结果，必须由可表示输入对的乘积产生，不在测试造数时提前舍入丢失。
