## 3. 网格/边界的关键可观测性限制（源码级推论，非新计算结果）

原rectangular_mesh为41×21、36×18mm：861节点、1600固定对角CST，
外边界120节点，内部741节点/1482个位移自由度；不细化、换基底或开裂网格。
原训练ROI严格abs(x)<16.2、abs(y)<7.2，648观测点共1296个位移分量。
这些数量来自已验收记录与原源码；将来分析仍须核对实际身份。
1482只是名义内部自由度，可能含未观测零列；实际active采样列数及数值秩
须报告，不能由名义自由度多于观测分量就保证零残差。

先按原sample_regular_mesh的三节点/重心系数构造稀疏线性采样S，并拆成
内部列S_F、固定边界列S_B。此ROI的单元不邻接x=±18/y=±9外边界，故源码
结构预期S_B=0。实际运行必须检查“非零边界采样系数数目为0”，不据此改ROI。
原bc由同一stage13/14训练DIC插值构造，不是独立边界测量真值；固定它只是
保持原问题身份，不意味着验证了边界的物理正确性。

重要后果：不施加平衡或平滑约束时，固定边界不能通过CST局部插值直接
限制这些内缩观测点。其真实影响是通过平衡方程向内部传播；本纯运动学
诊断不能把这一传播影响从平衡模型差距中单独分离，也不能说边界无关。
不额外释放/拟合边界做第二臂，因为在S_B=0时该对照的观测像空间本来相同。
若实际S_B非零或原ROI/网格不符，停止并另审身份，不自动放宽边界或换支持。

本方案因此区分“原网格/采样能否表示”与“特定平衡解的剩余偏离”，并明确
边界直接表示约束在本支持上不可见；不冒充网格、边界、材料的三个独立因果份额。

## 4. 观测、自由度与共同刚体商

所有向量按原顺序逐点[U,V]堆叠；原648个ID/坐标/正面积权重全部保留。
训练目标v=train_v，坐标取stage13；不重施header旋转、不分侧注册、删点、
重新拟合背景或以误差选择支持。这里的U/V是原全局分量，不叫真实裂缝切/法向。

U0的边界分量严格等于原bc，内部设0，仅是参数化的仿射原点，不是平衡解；
F为内部自由度的插入矩阵。所有候选U=U0+Fz都保持原边界；不引入q、损伤、
E、nu、Gc、长度尺度、应变/位移幅值或连续性阈值的拟合。

定义W=sum_i w_i，D=diag(repeat(sqrt(w_i/W),2))。权重只在计算中归一化为
面积加权RMS，不写回原文件。R是同648点加权质心定义的三列刚体基：
两平移及(-y_centered,x_centered)转动；不使用已消费高载的646点掩模。
H为DR的薄QR正交基，Q=I-HH^T；检查rank(DR)=3。Q是欧氏加权空间投影，
不是把未加权投影直接作用于带权矩阵，也不分别对三臂/区域/接口拟合不同空间。

```
y = Q D (v-S U0)
A = Q D S F                       # 最大1296×1482
J_kin = min_z ||A z-y||_2^2        # mm²
RMS_kin = sqrt(J_kin)              # mm
```

这是“离训练数据最近的运动学表示”控制，不是预测器、模型修复或可执行物理
状态。最优残差/观测投影唯一，不代表z或全节点位移唯一；不按最小范数节点场
外推新剖面或制作“oracle裂缝场”。1296观测分量对1482内部自由度，且刚体
投影再降至最多1293维，欠定/近零训练下界完全可能，不构成模型成功。

## 5. 一次线性分解，避免任意节点解与正则化选择

未来实现固定一次thin SVD：A=L diag(s) V^T，SciPy float64、gesvd，
不做正规方程、stiffness装配、迭代物理解、正则化/平滑参数或秩扫描。
固定数值秩cutoff tau=1e-12*s_max，L_r仅保留s>tau；记录全部奇异值、
有效秩、原自由度数、观测维数及有效零空间维数。A全零、非有限或SVD失败即停。

```
p = L_r L_r^T y
r_kin = p-y
J_kin = ||r_kin||²
```

只保存训练观测投影和残差，不需要选择或解释某个z。这个下界严格指
规定数值秩下的观测空间；若存在奇异值在[tau/10,10*tau]内，则“数值秩
未分辨”，保留取证并停止解释/不自动改cutoff或重试。该数值保护不是物理阈值。
薄QR、投影与SVD重构、正交性须通过合成测试及将来运行的算术核对。

三组已有平衡场U_k均不重求解。先核对边界U_k[B]==bc、原648点采样
S U_k==*_sampled；任何不符即停，不将不可行旧场硬纳入比较。

```
b_k = Q D (S U_k-S U0)
r_k = b_k-y
d_k = b_k-p
r_k = r_kin+d_k
J_k = J_kin+||d_k||²                # r_kin 与 d_k 正交时
```

检查三臂b_k位于保留的col(A)（在冻结算术容差内），才使用平方加法。
逐点/平方恒等式及交叉内积都核对，不假设RMS本身可加。||d_k||²只叫
“已有平衡场距离最佳运动学观测表示的差距”，不叫材料误差/边界误差/噪声。
若某截断奇异模态使旧场不能在容差内落入该空间，停止，不改rank来救恒等式。

向量mm检查rtol1e-12、atol1e-15；平方/内积mm²检查rtol1e-12、atol1e-18。
无量纲正交/采样矩检查rtol1e-12、atol1e-12。交叉内积的零判断用
abs(2*r_kin dot d_k)<=1e-18+1e-12*max(J_k,J_kin,||d_k||²)，避免对0仅用相对误差。
数值秩、算术或嵌套性不清，只能记该下界不可判定，不否定整个数据路线。

## 6. 判断尺度与结果—下一步映射

唯一主量是原648训练点、原权重、共同刚体商下J_kin/RMS_kin。
同一支持下报告三个J_k和可加平方差作为解释账本，不用MAE/新区域/新剖面
重选方法；E016 MAE、E017高载MSE和E018等权配对范数都不是此新下界。
选择L2只为取得可核验正交投影和下界，不为用旧MSE收益重选赢家。

没有独立噪声底或物理容差，故不预设“低于某百分比就物理通过”。冻结同一
T=(1e-15mm)+1e-12*max(||y||,max_k||r_k||)，单位mm，仅区分算术可分辨性，
不是真实测量精度。最大值只用于三臂共享数值尺度，不产生总判定或选择赢家。

对每臂k分别定义g_k=||d_k||（mm），按RMS_kin<=T / >T及g_k<=T / >T
记录下面四种状态；“该臂接近下界”仅指g_k<=T。若在平方表中分类，等价
使用J_kin<=T²及||d_k||²<=T²，不得将mm²的J直接与mm的T比较。
old/proxy/intact均逐臂记录，不以any/all、均值、最优臂或新百分比合并判定。
同一RMS_kin在三行重复只是共同对照，不是三个独立结果或三次下界计算。
实际active列、rank及下界仍未知；名义欠定不等于零残差保证。

| 观察 | 可改变的决定 | 不能据此声称 |
|---|---|---|
| RMS_kin<=T，g_k>T | 该网格/观测支持足够宽松；该臂下一项另审平衡假设/状态及独立依据，不盲目细网格 | BC无影响、q可辨识、噪声已去除或反演成功 |
| RMS_kin>T，g_k<=T | 该臂已接近此观测下界，先另审表示/采样支持可达到的精度，不首选自由物理参数拟合 | 该残差全是网格误差，或达到下界即物理正确 |
| RMS_kin>T，g_k>T | 对该臂保存两项限定差距，再择最小表示/物理诊断，不作因果百分比分摊 | 唯一材料、边界、三维或噪声病因 |
| RMS_kin<=T，g_k<=T | 该臂与共同下界均算术未分辨；此训练目标不再支持继续追拟合，先明确其他目标层次 | 已验证物理、去噪或未来预测，或可抹掉原指标差距 |
| rank/身份/采样/正交/预算异常 | 停止本次，记录不可判定及具体缺口，另审修复 | 数据路线全失败，或自动重选秩/网格/阈值 |

边界限制必须单列：S_B=0只说明此观测空间不直接看见外边界自由度；
边界通过平衡产生的影响包含在已有平衡场差距中，不能从该实验中单独识别。
即使下界接近0，也可能是过参数化、局部不平滑节点位移吸收了观测变化；
不将其称可实现弹性场/可转移状态。后续验证仍需独立依据和新审查。
