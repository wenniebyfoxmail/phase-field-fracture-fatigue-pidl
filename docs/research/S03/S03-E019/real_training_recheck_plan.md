可核验的共同Q空间投影及残差账本，从而恢复训练侧表示诊断的可用性？

stage13训练增量。不是当前损伤反演C2，更不是未来预测或新留出评价。

唯一主要决定：新Q一致保留空间能否成为数值可采信的诊断工具。

## 4. 同一问题的构造与唯一干预（未来另批）

沿用原CST采样S、内部插入F与仿射原点U0（边界=bc、内部=0），不把
U0称为平衡解。固定外边界后，所有可参数化节点位移为U0+Fz。
按原权重定义D=diag(repeat(sqrt(w_i/sum(w)),2))，不写回权重文件。
R为同648点加权质心处的两平移和转动，DR经一次薄QR得同一个H；
Qx=x−H(Hᵀx)。H有限精度下非严格正交，后续Q检查不能省略。

```text
y = Q D (v - S U0)
A = Q D S F
b_k = Q D (S U_k - S U0), k=old/proxy/intact

A = L diag(s) Vh            # 新分支一次gesvd，float64，full_matrices=False
tau = 1e-12 * s_max
Lr = L[:, s > tau]          # 模式选择只发生这一次，不扫秩

B = Q Lr                   # 修复数据流恰好一次Q
B = U T                    # 一次无主元economic薄QR，正对角符号规范
p_new = U (Uᵀ y)
r_new = p_new - y
```

生产阶段拟恰好1次SVD、2次薄QR（DR→H和B→U/T各一次），不含将来另批
的人工测试；0次FEM/刚度装配/物理参数拟合。检查用Q只读，不回写数组。
不是每臂一次SVD/QR；三臂共享y/H/A/Lr/U/p_new。
所有原tau及保护区间保持；若任一s在[tau/10,10tau]内、A全零/非有限、
分解/维度异常即停，不改driver、cutoff、精度或删除列继续。

真实模式数r由同一tau确定，**不是沿用合成的五模式**；修复前后必须都
是r列。r若不同于历史rank1203，记录差异并暂停进一步解释以另审复现身份，
不强制r=1203、不得用旧记录改新选择。历史数值本身不作为独立真值。
T对角必须正、有限，eta=||I_r−T||∞=max行和|I−T|≤1/2严格硬界；
不是最大元素、不是A的条件数，不作数值cond/SVD/找秩或降秩再试。

### 必须准确命名新的估计对象

有限精度下span(Q Lr)可能不同于span(Lr)；U不是A的新SVD因子。
本轮目标是“同一训练问题的Q一致保留空间残差”，不能自动称原A全部
列空间的严格精确下界，更不是物理噪声底。不得将U与旧s/Vh拼成新A。
保留同次新SVD产生的旧路径p_legacy=Lr(Lrᵀy)、r_legacy作为内部对照，
只记录其Q状态，不要求它必失败。它不是原E019旧运行逐bit重现。
新脚本若需要补投Q、改H/y/权重、换rank或重复QR才能通过，则停止本候选。

## 5. 主要数值条件与最小结果账本

全部原比较形式与单位保持：rtol1e-12；matrix/无量纲atol1e-12、vector
atol1e-15mm、square/内积atol1e-18mm²。T分类尺度不能覆盖恒等式失败。

必要条件按顺序核验：

1. 原来源身份、点/网格/BC、三场BC及采样一致；S_B非零元数=0和SU0=0
   是原ROI预期，若不符即停，不改变ROI/边界。S_B=0不排除平衡传播影响。
2. H正交/DR重构、Qy=y；原SVD重构/正交/截断保护及保留r列身份；
   新UT=B、UᵀU=I_r、eta和QU=U均通过。
3. p_new=U(Uᵀy)、r_new=p_new−y、Uᵀr_new=0、Qp_new=p_new及
   Qr_new=r_new通过。此处无已知真实解析p*；正交投影特征条件提供
   对声明子空间的数值证书，不能照搬合成解析真值结论。
4. 每个b_k都先通过Q及b_k≈U(Uᵀb_k)的位移容差检查，再核
   r_k=b_k−y、d_k=b_k−p_new、r_k=r_new+d_k和平方账本；
   不把不可行b_k投回U空间充当原模型，不改变三组冻结响应。

```text
J_Q = ||r_new||², RMS_Q=sqrt(J_Q)
J_k = ||b_k-y||²
gap_k = ||b_k-p_new||
J_k = J_Q + gap_k²              # 仅在像内/交叉项条件通过后使用
```

交叉项仍用原规则：|2 r_newᵀd_k|≤1e-18+1e-12 max(J_k,J_Q,gap_k²)。
逐向量和平方都核验，不说RMS可加、不把平方占比叫材料/边界/噪声份额。
同648支持的J_k不替换旧MAE、646点指标或37对剖面范数，不重新排名。

保留原算术判别T_mm=1e-15+1e-12 max(||y||,max_k||b_k−y||)，逐臂记录
RMS_Q/gap_k与T_mm的关系，仅为算术分辨状态，不是物理成功阈值。
新主判断不要求任何指定的RMS_Q大小或较旧记录改善百分比。

参考路径预先分开：float64 producer、独立fsum（float乘积再求和）和
实际保存float精确导入Decimal80。p/r与低秩H方向的完整向量核对适合
高精度；大r×r Gram/UT等矩阵的独立全量核验路径及预算在代码方案中
另行冻结，不能默默把全部大矩阵改成Decimal80而超时，也不能只抽几列
就声称全空间已验收。Q的向量/通过状态路径差异专属分流未解决；不额外
要求归一化ratio跨路径相等，不用参考值修写候选。未通过即停止解释。

## 6. 如何服务DIC反演，而不把运动学投影当相场

本实验输入：训练DIC的v/坐标/权重、固定采样/网格/BC及三组已有节点场。
本实验输出：H、声明保留空间、Q一致p_new/r_new、三场差距及可信数值账本。
**它不输出损伤参数q、相场d(x)、E/Gc或疲劳规律。**

未来另批低维损伤反演时，才定义固定先验中的d(x;q)与正向位移u(q)，
保持同一观测算子和共同刚体商：

```text
b(q) = Q D (S u(q) - S U0)
J(q) = ||b(q)-y||²
```

若候选b(q)也经独立检查落在该声明保留空间，才有同一平方分解；否则
不能套用当前三场账本。实际拟合仍对原y，不把p_new当去噪真值/监督标签，
不反演任意运动学节点场。新工具用来判断应先处理观测/表示可达性，还是
有必要审查边界经平衡传播、先验几何/模型，再准备q的独立敏感性检验。

q可辨识性必须另看同一Q/D下G=∂b/∂q、不同参数响应的等价性、观测误差
尺度及独立物理依据；A的运动学rank不能代替G的rank，old/proxy/intact
也不是自动合格的q有限差分。训练损失变低不是材料属性被唯一识别。
位移控制下绝对E等尺度不可由此凭空识别；Gc/长度尺度/疲劳参数更不在
当前输入中获得独立约束。下游先做最小敏感性方案，不在本分支增加q。
当前状态反演即使成立，也需演化模型与新验证信息才能预测后续cycle；
stage15已消费，不当新留出，本方案及未来该训练诊断均不读其响应。
