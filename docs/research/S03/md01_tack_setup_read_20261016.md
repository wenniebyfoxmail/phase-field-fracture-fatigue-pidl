## 4. 最小基线试验建议（仅建议，未执行）

按“先看到相对基线的收益”的目标，用最小C3图像可观测量探索，不把物理
开口标定或跨梁泛化证明加入早期主判据。保留现有半深度图像宽度定义，
它是图像剖面的宽度，不改成LVDT位移。不训练模型，不做多相机合并。

### 先做一个必要且小的身份连接

下一项待审批动作建议：**只读`Labbtest.xlsx`的工作表名／表头，以及图像
编号—名义荷载步对应所必需的字段；同时只列`Fixed Camera`文件名元数据**。
不读位移、LVDT或其他结果列，不开原图。先列字段白名单；如没有可安全
分离的名义标签／image-ID表，记录该缺项，不把实测力或文件序号冒充L*。
本轮未执行此动作，实际字段名／成员URL尚未解析，不能称连接代码已就绪。

### 随后最小计算包：一个固定剖面、三停点、一次查询

在上述连接确认并另获图像／计算许可后，登记精确的3个连续荷载停点及
每停点**按预定图像编号选第一张Side A固定图**，不是每停点挑最清晰或最
低误差的图，也不是把三次同停点曝光当三历史。用起点已可见的裂缝段固定
一条剖面和法线，仅依据允许历史；开目标前保存几何／位置和预测。
起点需两条可测的同定义历史，不能按未来宽度挑起点。若历史不可测，保留
E原因；若目标不可测，保留R缺失和已保存预测，不找邻点／换图救分。

| 小试验项 | 拟议内容 |
|---|---|
| 单位／范围 | 一根来源待排重的MD01梁、一条固定测线、两个历史停点→下一个给定停点；明确是探索性单案例，不是独立样本总体效果 |
| 输入／目标 | 只用前两停点半深度宽度与名义标签；目标是第三停点同定义宽度。nominal+1kN次序须先由连接确认，不用图像序号或后张力代替 |
| 主基线 | Persistence：下一宽度预测等于最近历史宽度w2 |
| 最简单候选 | Secant：确认等间距1kN时预测2w2−w1；否则用实际已核名义间隔。保留现有输出映射，不为新目标调公式；新图像尺度下旧采样窗／映射是否适用只用允许历史检查 |
| 一个主比较 | 同一可评分机会上的绝对误差（单例即MAE），`error_secant < error_persistence`即该例基线收益，报告差值；不叠加任意百分比、显著性或物理精度门槛 |
| 配套记录 | 3次测量的有效／原因、E/Q/R、两臂输出及保存顺序、共同支撑。无效不补0；无共同支撑则本例尚不可比较，不把资料研究整体判失败 |
| 最小结果图 | 三停点同定义宽度与两预测、同一评价机会的误差对比；按预定ID展示，不按效果挑图 |
| 得到收益后 | 记录探索性方向增益，再前向扩展少量停点；不宣称已跨梁／道路泛化。未胜过persistence时保留数据连接／测量进展，不立刻加神经网络或按目标改定义 |

这不是已冻结的新Experiment或运行授权；精确图像ID、起点和输入单位尚
需上述连接及允许历史确认。最小建议只要求能解释比较的字段，不要求先
完成整库审计、多相机标定、所有停点、所有case胜出或独立物理真值。
