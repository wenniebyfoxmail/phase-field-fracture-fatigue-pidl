# S01-E012 Stage B：冻结 E003 补评分与增量证据资格

日期 2026-10-16；协议 S01-E012-B-v1；主属 Storyline S01 / Experiment S01-E012。状态：冻结版本430b656f5b42065209c44285801e2b8a05560972已通过6.1 sol-Medium独立设计审查；实现已完成并送独立代码审查；未执行。拟议独立 Run 为 S01-E012-R003。Stage A 的源代码、R001停止和R002结果不改写。

## 决策、范围与比较

问题是：用不变的 E003 对已固定的修正块补齐评分后，能否得到分布更广、身份明确的正增量效用证据，足以支撑下一次受约束的学习方案？类别 C1，真实道路的已用训练证据；单位是图像中的不同 GT 身份及地点，不是多个相似修正框。当前静态图像，无未来预测时点或跨时间结论。

唯一输入候选是 R002 固定清单的 31,156 行、835 图、12 地点；43,347 个原框从既有 E007 银行按同样白名单解析。R002 已观察到几何覆盖 749→760（+11 GT/5 地点），但它不是新增检测数或增量效用上界。即使源组2没有新增几何覆盖，也不能排除提升原已覆盖但原先未进入预算的目标；所以不能只评分那11个几何新增或删掉组2。

353/1459/2028/5982 四个反复使用的资格地点隔离，不加入本轮标签或评分。验证、新确认和预留地点继续封存。E003编码器历史上使用过既有训练地点；每行修正器虽排除自己的held组，其他FIT行的修正器可能使用当前held GT，故三组是支持分布检查，绝非端到端独立泛化验证。

原 E003 行的坐标、概率、分数、candidate_id、源parent、顺序均保留。不得重评分原框、生成新候选、运行YOLO或重新预测修正器。sparse source_parent_key 不可当数组下标；用明确源key映射适配既有函数，输出仍保留源身份；并列框、分数组和原框先于追加框的稳定顺序不能改变。不得调用继承的全量load/validated_cache。

## 不变的评分链

在未来已批准的 producer 上先验证 R002包/逐文件锁、31156行映射、三组OOF来源、835图路径/hash/尺寸及E003 checkpoint hash。只打开锁定清单中的12地点图像；将文件字节读取一次、hash通过后从同一字节缓冲解码RGB，避免hash与解码之间文件变化。每图只解码一次，处理完其最多40个修正块后关闭；图片不复制到新训练集或Mac。本轮设计不访问这些像素或模型。

同一个 E003 best_ranker.pt（hash bc304c5f…e22e65）同时提供 MobileNetV3-small features/avgpool 和 classifier；权重不改变，全部 eval/inference_mode、FP32、无autocast/反向。沿用E008：pad_box(.1)后clip与Python round，边界逐项等于R002清单；RGB→Resize((224,224))→ToTensor→既有ImageNet Normalize，576维池化。清单文字中的standardization不新增任何特征拟合：实际E008没有特征标准化器。

每图一次GPU backbone batch（≤40行，批上限128），835批、31156新crop rows。保存31156×576 float32池化特征（71783424 bytes），冻结classifier在CPU按512行批次评分一次，再用保存特征独立重放一次验证；两次head合计62312行，绝不重跑backbone或再读原图。概率全部有限且在[0,1]，CPU同实现/同批界的重放必须精确一致。

冻结torch/torchvision版本、物理GPU1/UUID与CUDA_VISIBLE_DEVICES=1→logical cuda:0；设备或版本不符即停，不换GPU/CPU。具体后端flags见config。历史E008未逐项保存backend flags，故本方案不承诺新卷积输出与未保存的历史环境bitwise一致；承诺固定权重/架构/裁剪/预处理/FP32及可精确重放的当前CPU分类头。若实现检查发现预处理或checkpoint结构与E008不一致，返回修订审查，不能在producer临时补偿。

## 评分后按原预算核算收益与伤害

只能在全部评分验证通过后计算 GT-free 静态资格：s0=sqrt(原proposer_confidence×修正E003概率)，s0严格高于原分数；不等于已有原框、与任一原框IoU不大于.7。ineligible 与缺失分别记录，不把它们伪造成零效用训练样本。

沿用既有1FP/image、IoU=.5、全同分组原子前缀和GT匹配顺序。全12地点建立原E003 baseline；三个FIT8各建立自己的baseline。对各静态合格候选，单独追加一个修正并算 U=新增不同GT−丢失旧GT−该追加修正实际FP。GT身份固定(image_id,GT_index)，不同scope分别去重。总槽位最大 N+2N=93,468，不额外计算held baseline。held支持由 U_full12 按源组统计；FIT支持只能用对应 U_fit8。

复用已证明安全的first-excluded严格小于快捷路径；不得把等于边界的候选直接标0。若需更快的确定性算法，只能在合成稀疏ID/同分组/重复框/GT并列案例中与既有完整匹配精确等价，经独立代码审查后使用。复核使用保存结果与固定守恒关系，不重复93,468次U计算。

评分完整时只作一次GT-informed联合潜力诊断：U_full12>0负责选入，按s0降序/原lexical并列规则做correction-only NMS(.5)，按源key追加；不按U重排。重新计算原/新预算前缀、旧命中保留/丢失、新命中、净增、macro地点召回和FP类型。该旧命中分母是这835图的原E003命中集B12，不能冒称既有四地点282命中的验证；GT-informed结果不是学得模型或可达上界。

## 预算、可行性与停止

一次新Run；CPU1线程；全程（输入/hash/解码/评分/验证/标签/图表/打包前收据）≤3600秒；主进程与属于本任务的子进程合计峰值RSS≤4GiB，GPUallocated与reserved各≤4GiB。实现优先单进程，禁止DataLoader workers；如库产生子进程仍计入预算。预检必须选对GPU、无冲突且资源足够，不抢占、不下载权重或升级环境。

最多835次原图解码、31156新backbone crop rows/835批、62312 CPU head rows、93468 singleton槽、1次联合诊断。原框重评分、YOLO/新corrector推理、拟合/求解、四资格地点或验证比较均为0。沿用E012持久Windows内存探针，采样值不缓存，记录RSS/VRAM/耗时与计数。任何身份、非有限值、设备、重复运行或资源问题即停；没有自动换批量、预算扩展或R004重试。

已知静态工作集：池化缓存约68.5MiB；每图最多40个224×224 RGB float32输入约23MiB；最大原图1920×1080。几何/标签仅使用既有JSON和缓存。激活/后端内存和全U时延尚无本阶段实测，不能声称全量必然可在预算内结束。Code Ready前需合成边界测试与标签路径的可行性检查；不为此在Mac实际模型前向、拟合，或未批准使用producer。

若评分缓存已完成但U因资源停止，保留其身份和收据，报告incomplete_qualification而非无正例；另准备精确的cache-only算法修复方案，不重新读取图像/跑backbone。若评分阶段失败则保存有效已完成块及失败位置，但完整证据不成立；修复/恢复也须新Run和准确批准，不暗中补跑。

## 结果标准、分项价值和下一动作

有效性前提是31156条评分完整且来源/身份/数值验证通过、范围预算合规。主判定沿用已冻结L2：三个源组各至少1个U_full12>0的不同GT、各至少1个地点（合计≥3GT/3地点），且每个FIT8有正例和非正例。它针对旧四个正例集中两地点及稀疏FIT支持，只是最小分布支持，不是13参数或任何模型有充分样本量的证明。

L0可信补评分能力、L1新增去重正效用GT/地点、L2分布支持主判定分别报告；联合潜力及未来检测标准不另加为隐藏L2门槛。L2未达也保留真实正例/地点/分数与几何成果，不通过事后改阈值重命名为成功。结果为qualified_distributed_support、partial_useful_support、no_qualified_positive、incomplete_scores/incomplete_qualification或invalid_lineage。

若分布支持与联合潜力均成立，下一步另冻低容量/受保护学习方案；若支持成立但联合预算伤害旧命中，下一步先冻集合选择修复；若只出现部分支持，按实际GT/地点有效样本量约束下一个更窄方案，不立即在欠支持FIT上训练；若完全无正效用，停止本候选来源的效用头拟合，根据已测首个瓶颈，单独冻结候选几何、评分或集合选择的一项最小修复。不得回到同一旧缓存上搜索线性特征/L2/阈值。

最终学得检测收益的标准不变：同一1FP/image、IoU=.5，原E003命中保留≥.95、净增GT≥1、macro地点召回delta>0，且明确测试分母与地点角色。本Stage B不部署模型、不验证旧四地点282命中，也不证明新地点泛化；未来学习结果必须另作准确比较。保留原框本身不等于预算后保留率=1。
