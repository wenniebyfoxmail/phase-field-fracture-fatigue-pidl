# 真实训练正控制先行的多尺度区域学习

本次为 C2 real-road 当前图像、已消耗12地点条件OOF。目的仍为有益修正进入原前三并产生保旧净收益。设计→指定6.1 sol-Medium独立审查→通过后实现和测试；本次不执行真实训练、传送或公开推送。独立审查只确认设计/代码，不代表定位或检测成功。

## 对照与新增轴

E023使用冻结分类特征和41系数像素ridge，Brier .171709差于常数 .034257，前三/净益0。E024直接RGB小CNN但3折输出上限仅 .000739–.002208，前景Dice均0、Brier均差于常数，0折接入，下游未执行而非净0。梯度存在和loss下降均未证明能学习裂缝区域。

本次改变的是可检验的空间学习任务：先对真实train6样本做两固定种子正控制，再用具有整个context多尺度/跳接路径的独立空间模型、显式前景支持抽样学习区域。不是继续换缓存压缩器、41系数像素头、C/D定义或排序描述。没有新增人工标签/外部数据，新增轴是训练支持与上下文空间学习能力，不宣称获得了新的裂缝语义真值，也不对本组合中某个因素作因果归因。原819多边形仅区域包络，不能叫精确裂缝像素或宽度。

## 冻结模型与学习规则

RGB128/context、32x32格中心参考和几何坐标完全沿用E024。网络先area-average RGB到32格，再encoder双3x3 ReLU(8通道)、maxpool2、双conv16、maxpool2、双conv32，decoder bilinear align_corners=False上采样拼接对应skip，双conv16、再上采样拼接/双conv8，1x1输出logits；各conv含bias，无BN/dropout/预训练。此网络让输出利用更广上下文并保留浅层位置；输出还是区域而非物理像素测量。参数总数由精确结构计算后填入config，在实现之前补充固定结构的算术计数不算架构选择。

所有训练从头，AdamW lr .001/wd .0001、batch8。per-context loss = BCEWithLogits像素均值 + (1−(2sum(PY)+1)/(sum(P)+sum(Y)+1))，批均值。末层bias0，不用稀疏前景率初始化。正式模型seed25000+k，1024步，只用最终步。抽样固定seed，先地点均匀→该地点图均匀→第j行轮流选择该图的有前景/全背景context桶→桶内均匀；一桶缺失使用存在桶。不GT裁新框、不增强、不调loss/epoch/seed/阈值。平衡训练不改变自然分布上的评价或基线；可能损害概率校准，Brier基线照常否决。

每折固定8个不同train6图：按numeric site/image_id/index排序，每图首个0<前景格数<1024的context，然后首8。少于8则缺支持、不得连接，不替换规则。两个控制seed25100+k、25200+k，各128步，每步全部8个固定样本。控制只是重复训练样本能力检查，不是交叉验证。正式三个模型仍独立拟合，不因控制指标挑模型或多训练。

全部6控制和3正式模型最终状态先冻结，然后才计算控制/qualification指标；不得看中途loss选checkpoint。控制指标仅同8训练context等权，常数取这些8张的平均前景率，同时对全0/全1。两个种子都须各自Brier和前景Dice比最优简单常数严格改善>1e-6。此最低能力检验不设置任意高Dice门槛；通过说明可学出区域且重复两个seed，不证明泛化稳定。

资格仍E024的自然候选分布全行：Brier低于min(owntrain6常数,0,1)>1e-6；固定P>=.5的参考有前景context Dice高于max(常数二值,0,1)>1e-6。context→image→site等权，两个资格地点任一无前景为inconclusive。逐地点保留差异；控制和资格同时通过的折才接入，任一缺支持/失败固定E003/弃权。先保存全部控制和资格决定，再做任何role拟合。控制失败而资格通过也不接入，不事后降低标准。两种子是train-only复现能力，不把3重复资格地点宣传为总体稳定性证明。

沿用E024同C/D、4scalar+2C/D、11系数Q/N/A、FIT8/校准和GT-free正常推理。已通过的train6正式模型不重训，控制模型绝不接入。不改变正面积交集、原dup .7/accepted-only修正冲突 .5、cap1/image、cap3/固定四地点组、弃权及tie-break，不扫描交集/阈值/容量。保留全部E003原行和分数。

0折接入则停止StageB、所有下游retention/new/lost/net/macro/primary为null，不计算OOF，不伪造净0或684/684。至少1折接入则一次完整12地点条件OOF，未接入折仍E003/弃权，禁止只报有利折。唯一最终主标准不变：同1FP/image/IoU .5，旧检测保留>=95%、净GT>=1且12地点macro召回变化>0。三个必要项共同定义保旧净益，不由控制、资格、FIT排序或热图好看救结论。历史684旧命中不替代本轮比较。

## 结果标准、证据与下一动作

执行、控制、资格、检测四种结论独立记录。控制任一seed失败→当前训练配方不能稳定学会这组真实样本，保留样本/梯度/预测诊断并停止接入；不再微调本像素头。控制过但资格失败→训练能力已有，但跨地点/区域支持仍无证据，下一方案考虑标注任务匹配或独立合格空间来源，而非改排序。资格过但OOF净益未成→保留合格定位组件，再检查有益修正入池/前三/预算及效用支持。缺支持/缺指标→inconclusive。所有负结论保持，不另开暗臂救结果；本方案不自动启动后续方案。
