# S01-E003 result — 2026-10-12

## Actual detection benefit

One reviewed tile-native hard-negative ranker was trained for the frozen 15
epochs. Epoch 2 was selected by validation detection recall, not final loss.
On the unchanged tiled candidates and the same 302 FP budget:

- location-macro recall: 0.262757 -> 0.289509 (+0.026752);
- true positives: 110 -> 115; false positives: 302 -> 302;
- oracle-to-budget capture ratio: 0.384401 -> 0.423537;
- locations improved/declined/unchanged: 3 / 1 / 1.

This is measurable development-set detection progress. It did not reach the
predeclared +0.05 development gate. The freeze stage therefore stopped before
issuing test authorization; locations 1174, 1729, 2246, 2260 and 2485 remain
unaccessed. There is no new-location confirmatory result. The checkpoint and
training evidence are preserved for reuse, not discarded as valueless.

## Evidence and limitation

The 21-member evidence ZIP was retrieved and integrity/identity verified. Exact
scored rows reproduce the metrics. No second seed, architecture, score sweep,
proposer retraining or post-result gate relaxation was performed. Full 15-epoch
history is retained; later cross-entropy improvement did not increase operating
recall. A descriptive paired-location bootstrap interval for the selected
validation delta is [-0.003158, +0.064505]. Because this checkpoint was selected
on these same five validation locations, the interval is descriptive and cannot
establish confirmatory significance or population improvement.

## Next solution, grounded in the detection errors

Exact replay of the 302 selected candidate FPs finds 190 proposals whose crack
IoU is between 0.05 and 0.50, 20 duplicate qualified boxes and 92 proposals with
no/small crack overlap. Both highest-scoring montage FPs contain a crack but
have IoUs 0.361 and 0.344. Thus a crack-presence classifier can confidently rank
a visibly real crack that is still an invalid detection under the frozen metric.
S01-E003's hard-negative task deliberately excluded this ambiguous-IoU group.

The next intervention should rank **valid crack detections**, incorporating
localisation quality, rather than continuing the same background-discrimination
training. A new reviewed experiment can reuse these tiled train proposals and
fit a small valid-box calibration/ranking head using crack probability,
proposer confidence, normalized box geometry and explicit IoU-validity labels
from train locations. Partial-overlap boxes are invalid detections for this new
target; they must not be mislabeled as images without cracks. Start with the
simplest calibration model, fixed features and one training fit. If validation
cannot improve the same operating point, move to explicit box refinement rather
than another crack-presence ranker. Fresh confirmation remains reserved until a
new reviewed development gate passes.

This error decomposition motivates that repair; it does not prove that the
proposed calibration or refinement will work. No additional experiment was
executed within S01-E003.
