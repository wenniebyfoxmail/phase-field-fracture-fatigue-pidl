## 3. 误差定义：改评分标签，不改预测

记发布的x坐标为x_t，假设替代坐标为x*_t=x_t+e_t。e是一个假设偏差，不是新测量、已知真值或估计出的噪声分布。

原增量 y_N=x_(N+1000)−x_N。替代增量为：

    y*_N = y_N + e_(N+1000) − e_N.

四个原输出q_B0、q_B1、q_M0、q_M1全程保持数值不变。仅重新计算与y*的绝对误差。尤其**B1不重新从替代坐标计算secant**；它此时是“原secant预测的冻结输出”。不重新生成特征、不重新标准化、不加载模型做forward、不调用原fit入口。

这保留了原“增量预测”的评分对象。必须避免以下混淆：原绝对预测x_N+q如果也被冻结、再只对x*_(N+1000)评分，误差只含未来端e_(N+1000)，属于另一个问题。本协议不把那种未来端单点扰动当作本分析，也不混用其2ε界。若绘制示意，展示增量，不把x*_N+q说成冻结的绝对位置预测。

固定预测依赖原来含误差的x/y、近期增长、boundary输入和训练标签；本分析不会消除这种依赖。它衡量的是标签解释变化时固定输出的排名稳定性，不是errors-in-variables校正，也不是“更准确数据训练后的性能”。

## 4. 主分析：有界坐标误差下的确定性保证

默认对两个记录使用同一个数值ε，约束所有相关节点`|e_t|≤ε`。不假设独立、零均值、正态或时间无关；允许任意时间相关，但必须满足共享节点一致性。两个记录分别计算，再等权平均，不按147个窗口池化。

定义：

    D_r(e) = mean_N ( |q_M1,N − y*_N| − |q_M0,N − y*_N| )
    D(e)   = [D_F(e)+D_FF(e)]/2.

**主判据是保守下界是否严格大于τ=1e−10mm。** τ只用于浮点边界，不是物理收益阈值。不计算p值或iid窗口置信区间。

### 4.1 第一层：不依赖误差排列的解析界

绝对值为1-Lipschitz，故单模型MAE变化不超过2ε，两个模型的MAE差变化不超过4ε：

    D_r(0) − 4ε ≤ D_r(e) ≤ D_r(0) + 4ε,
    D(0)   − 4ε ≤ D(e)   ≤ D(0)   + 4ε.

若未来对两个记录采用不同上限ε_F/ε_FF，则等权总差的变化上界为`2(ε_F+ε_FF)`；本版不扫描双参数矩阵。

由旧标量结果直接推导的**充分保证半径**（不是新扰动试验结果）：

| 聚合 | D(0)/4，mm | μm |
|---|---:|---:|
| F |0.012876656743381471|12.876657|
| FF |0.0008714361350999379|0.871436|
| 两记录等权 |0.0068740464392407045|6.874046|

上限严格小于该半径（并满足τ裕量）时，这个通用界就足以保证对应的M1更差。超过该半径只是此通用保证失效；**不表示已经翻转，也不表示临界误差就是该值**。总均值可能有保证而FF单条没有保证，必须并列展示。

### 4.2 第二层：逐边精确、全轨迹保守的外包络

对每条边，令z在区间`[y_N−2ε,y_N+2ε]`内，f_N(z)=|q_M1−z|−|q_M0−z|。它是分段线性函数，其极值可在区间端点及落在区间内的q_M0/q_M1求得。

- 对f_N的逐边最小/最大值分别按record平均，得到L_row/U_row；再按记录等权平均。
- 与4ε区间取交集：L=max(D0−4ε,L_row)，U=min(D0+4ε,U_row)。
- 所有可实现的共享节点误差路径的D必在[L,U]内。但逐边分别取极小值可能要求同一节点有矛盾的误差，因此**这只是全轨迹的外包络，不是可达到的全局最坏值**。不得拼接逐边最优扰动作为真实路径。
- L>τ可给出整个有界类的排序保证；L≤τ只能记“该界未能认证”，不能说已存在翻转。因为e=0始终属于集合、原D0>0，本误差类不能推出“所有允许误差下M1均更好”。

本版不引入MILP、参数搜索或随机模拟求全局最坏路径；不把图优化器的求解误称为模型训练，也不在此准备阶段执行任何优化。

## 5. 有限情景：只找具体例子，不估计概率

在同一个ε网格上，按每个record独立排序的端点集合t_j，j=0…m−1，定义s_j=2j/(m−1)−1；m<2视为输入失败。不使用误差大小挑选节点。

| 固定误差路径 | e(t_j) | 用途 |
|---|---|---|
| 无扰动 |0|恢复原表 |
| 常量正/负偏置 |±ε|验证增量中常量偏置严格抵消；不代表绝对定位无偏 |
| 缓慢漂移正/负 |±εs_j|代表跨记录区间的累积漂移假设 |
| 交替正/负 |±ε(−1)^j|高频压力情景；绝非实际噪声模型 |
| 中点阶跃正/负 |j<floor(m/2)为−ε，其后+ε，另取相反数|局部参考跳变假设；不是编号异常的修复 |

ε单位mm的固定网格：`[0,0.00214,0.00428,0.00856,0.01712,0.03424,0.06848]`。分别对应公开包8.56μm/pixel下的0、0.25、0.5、1、2、4、8pixel，**仅作数值尺度参照**；这些既非F/FF误差估计，也非从2015文献转移的校准。网格事先固定，不因结果扩大、加密或挑选。

共9条路径×7个半径，分别报告F、FF及两记录同名路径的等权值（不枚举跨record路径笛卡尔积）。原坐标不覆盖写入；e只在分析内存/新产物中作为假设。

若某个一致路径出现D<−τ，称“在指定误差上限下找到固定输出排序反转的数学例子”；D在±τ内称“无法区分符号”。这不说明该路径物理可能、发生概率或真实标签已经支持M1。首次出现反转的网格点只给可实现反转半径的上界，不是最小临界值。有限情景都不反转，也不能替代第4节的全类保证。

次要比较：四臂各自MAE及冻结B1与M0/M1的差；使用相同标签路径，绝不为每个模型单独抽误差。它们解释简单外推的稳健性，不改变主判据。相对百分比不是本分析主指标。

## 8. 能判断与不能判断

**能判断（以假设成立为条件）：**

- 原固定输出的排名能否承受给定的标签x坐标误差上限；
- 排名保证在F/FF间是否不对称、等权总结果是否掩盖更脆弱的单条记录；
- 是否存在某些一致的数学误差路径能改变排名；
- 后续作者误差资料需要提供哪种单位、量级与时间关联，才能与此条件分析对接。

**不能判断：**

- F/FF真正误差多大、哪个路径真实、偏差与重复性分布、95%概率或发生风险；
- 公开等效弹性裂尖是否准确对应几何裂尖、SSY失效造成的模型偏差；
- 误差是否导致旧负结果，或去噪/重测/重训之后历史是否有用；
- x/y/近期增长/boundary特征与训练标签的联合测量误差效应；
- 未解决的首列/999时间键、15/16kN、未来帧处理是否可接受；
- 新试样、未曝光尾段、道路预测或总体泛化。

作者如果提供SD或重复散布，不能自动把它当硬误差上界ε；若提供的是相同图像重复操作误差，也不能包含相机/DIC系统误差或物理准确度。需先匹配定义和适用cycle，再用有依据的界或另立概率协议。本补充不自动转为训练许可。
