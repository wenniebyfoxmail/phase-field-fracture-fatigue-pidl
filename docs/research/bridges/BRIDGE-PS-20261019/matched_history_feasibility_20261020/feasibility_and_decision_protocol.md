## 1. 这次究竟验证什么

上轮“历史不同”有两种含义，不能混用：

1. **响应历史不同**：相同名义加载下，过去的几何、位移或传感响应不同。可以做观察性的预测信息比较，不自动识别加载历史的因果效应。
2. **加载路径不同**：过去载荷的幅值、顺序、循环数等被控制为不同，在匹配时点后施加同一未来加载。这需要原始试验确有这种设计，或新物理/合成分叉。

信息集明确为 I0＝当前几何/响应、材料/边界、当前相位和未来计划；IC＝I0＋已知过去加载/年龄；IH＝IC＋响应历史。Q1只针对I0，Q2比较IC与IH。

三个互不蕴含的科学问题：

- Q1 当前几何/响应（以及当前和未来加载）单独是否遗漏影响未来的状态？此问题暂不把完整过去加载作为已匹配输入。
- Q2 允许使用的响应历史能否补回这些信息，超过已知加载历史和暴露量？
- Q3 这种收益能否迁移到未见试样、加载方案、材料或真实域？

“完整状态不同”不等于“图像历史能看出来”。例如退化尚未起效时，累计疲劳量可能已不同，而当前与近期位移几乎一致。反过来，已知完整加载与材料的模型可能已经解释累计量；不能故意删去已知加载、循环年龄等输入，制造历史响应的收益。

## 3. 最少缺什么，能怎样补

### 3.1 本地可补，不需要新试验

- 生成 `specimen/parent–frame–cycle–phase–reference–coordinate–load–target availability` 对照表，未知字段保留空值。
- PHM恢复已有加载谱、光学/信号共键与同sensor-path候选池；将T4冲突隔离，不能猜7054应改成67054。原有固定跨度方案只有5窗/4试样，不把它夸大为所有可能方案上限，也不为凑样本任意放宽。

- 对现有FEM候选核查完整输入状态与冻结观测算子，而非先生产新大库；已有数组的离线评分需按原owner数据边界具体化，不复用旧teacher标签。

### 3.2 向作者索取的最小包

先取得**文件索引与几行schema示例**，再决定搬运全量数据。字段优先级：

1. 试样/母core/母板/几何与初裂纹ID，历史路径是否真实不同。
2. 起点前的frame↔timestamp↔machine-cycle↔load/phase↔reference映射，以及起点已知的未来加载计划。名义Hz不能替代此表。
3. 独立裂长/几何的原生观测及测量定义、重复读数/误差；不以平移台精度代替裂尖误差。
4. 同一物理状态/相位下重新采集的图像或传感重复，以及稳定背景/坐标标定。

PHM优先补原有Baseline、T7/T8后期信号、T4周期证据、光学误差及预裂历史；SCB优先六试样与母core清单、同步加载与双目原图、独立裂长。Mendeley优先采集映射与独立光学锚点。少量锚点可以判断测量方法是否可行，不能代替正式未来评分标签。

### 3.3 不能靠整理补出来的条件

如果原试验没有“不同过去加载→共同续载”，必须取得已有这种试验，或新采集/新仿真。若缺同状态重采，也不能将相邻时刻、不同机位或重复跑算法称为采集误差。

新物理试验建议以同批/同母材为分组因素，预先分配至少两类过去加载路径，在预定义当前几何窗口和共同探测加载下进入统一续载。完整原图、机器记录、独立几何参考一起采集；记录温度、停载与黏弹松弛。具体试样数须由重复性与预期可分辨增量确定；现有资料不足以承诺“六件即可显著”。沥青停载不是无物理效应的操作，不能直接套用金属或准静态相场的记忆机制。

## 4. 自建 synthetic：推荐生成什么

目标是一个**观测信息与历史可恢复性的挑战集**，不是先渲染大量逼真裂缝图片。

已有native状态对象包含u、d、累计A、当前driver r、f及身份/父链；当前实际更新为 `A_new=A_old+max(r_new-r_old,0)`。Carrara原文提供累计变量和加载/卸载更新的机制依据，但原文有不同选项，不能代替本实现验证。所复用完整预印本见 [Carrara PDF](</Users/wenxiaofang/obsidian/01 Research Tracks/Paper Reading/1 paper 原稿/Carrara et al - 2020 - A novel framework for fatigue behavior with variational phase-field - arXiv2018v1.pdf>)，§3.1 Eq.(19)、§3.3 Eqs.(35–36)、§4.1 Eqs.(41–43)；[官方记录](https://arxiv.org/abs/1811.02244)。

可用的两层数据必须分开：

- **已有场的虚拟观测**：按已声明空间分辨率、采样点、坐标扰动生成几何/DIC-like观测。能检查测量压缩与噪声；不会创造新的物理加载历史或独立试样。
- **合法历史分叉**：从同一初始化和材料/几何出发，沿不同实际加载日程连续求解，在预先规定的当前观测窗口匹配，随后共同续载。只有这层能主动构造本问题的加载对照。

现producer是重复基础cycle乘一个幅值系数，未有通用逐cycle日程与分叉restart接口；原比较合同要求schedule相同，服务的是同物理问题三种求解初猜。需新增独立的“前史可不同、当前匹配条件与未来日程相同”的比较合同，保留原合同，而不是删除身份核查。

## 5. 合成主实验 S：当前观测是否遗漏状态，历史能否补回

### 5.1 候选设计规模与原点

提出12个预先指定的geometry/material参数family（数值设计点，不是假定12个真实独立试样），每family两种主要预历史，两个未来跨度。全部family在同一已明确物理模型范围内；不混入道路、沥青与金属的不同机制。

- 主要历史：相同预循环数、不同亚临界幅值/暴露，然后共同探测与续载，以避免仅靠循环年龄区分。低幅多循环与高幅少循环可作为另一个预先声明的开发问题；不能看结果后在两种定义间切换。幅值/循环日程在开发侧确定后冻结。
- 顺序交换仅在该本构确实可能区分时才作为后继物理假设，不因“有记忆”就假定高低载顺序一定产生不同未来。
- 原点只依赖起点前数据：几何窗口、当前加载值/加载分支、统一探测相位。不得根据未来裂长、事件时间、最终寿命或分歧大小挑原点。
- 每family的两条历史均从完整合法parent推进，不手改A/H，不把不同轨迹的d、u、历史拼在一起。停载/探测阶段如产生状态演化，照常提交，不能重置累计量。
- 匹配包括完整允许几何、边界/材料/初裂纹、共同坐标和当前加载相位。分别考察“只给几何”与“几何＋当前稀疏响应”的匹配是否仍有共同支持。
- 在当前条件匹配后施加同一未来日程；拟用5和20cycle两个跨度是设计值，必须按所选生成器的演化尺度在开发侧冻结，不沿用Mendeley发布H。

配对失败、尚未疲劳活跃、匹配误差超过容差均记录。不能放宽容差直到出现分歧，不能用未来结果决定保留哪些family。若当前条件没有共同支持，则报告该设计不支持“匹配对”判定，转向连续条件预测问题。

### 5.2 观测算子与输入公平性

对每条轨迹同时保存完整状态（仅oracle）和可部署形式的观测：

- 几何：声明的d→可见区域算子，阈值/分辨率只代表synthetic定义；不是物理裂纹真值。固定主算子，并用预定分辨率/阈值扰动检查结论是否依赖该定义。
- 响应：从u提取稀疏位移、开口或DIC-like场，必要时保留独立反力通道；不将真实A/f/全场d混入普通观测特征。
- 三类版本：无噪声；同一状态重复测量的已知测量扰动；带时间相关参考/坐标扰动。噪声副本不增加独立样本。
- 所有普通预测臂拥有同样的已知材料/几何、循环年龄、起点前加载记录与已知未来加载计划。过去加载摘要若压缩，另检查全加载记录强基线，不能将其压缩损失误报为响应历史必要性。

### 5.3 比较臂

| 臂 | 输入与作用 |
|---|---|
| P | 保持/当前增长简单外推，输入边界同上 |
| C | 当前几何＋当前响应＋已知过去/未来加载与暴露量，强当前基线 |
| H | C＋自身响应历史，唯一主要候选 |
| D | 当前输入不动，换成训练侧匹配family的历史；共同支持不足则此对照不可解释，不强行配对 |
| R | C＋同状态重复观测，信息预算匹配，用于判断H是否仅在降噪 |
| O | 完整当前状态的预测控制；真实A/r/f等只允许在oracle分支 |
| O+H | 仅无噪声null分支：O加冗余历史，同模型/同预算，诊断有限近似/正则化效应 |

使用同一个小型有限预测族及相同选择预算；原点/跨度/尺度按family分组。R只在带噪分支需要，不必机械扩成全因子网格。新增Transformer/PIDL不是本实验变量。

完整状态还须做**native restart重现**：同完整状态和同未来日程重现参考，是状态保存/转移的实现检查。若学习型O不如native重现，说明有限近似器存在误差，不可将它直接归因于观测缺信息。

### 5.4 对照、主指标与判定

无遗漏记忆的null为：当前输入含生成器全部演化状态且无噪声。条件于完整状态和加载，旧历史不应提供新的确定性物理信息；有限模型可能仍从冗余特征获益，所以同时检查native重现、O与O+H。若O+H改善有限模型误差，只解释为近似/正则化/选择效应，不称新物理信息，也不要求这一数值差严格为零。`fatigue_off`不自动是memory-free，因为仍可能存在不可逆d/H。

两项结论分开：

1. **Q1 当前信息缺失：**当前观测落入冻结匹配容差，而相同续载下的未来几何增量差超过数值/观测算子/匹配扰动的预定敏感性范围；同时完整state能重现各自未来。近似匹配只支持对该观测精度的结论，不声称严格相同全物理状态。此处匹配的是当前观测集合，不是C的全部输入；两条过去加载本来就不同，故不能据此声称“C连已知完整加载历史也信息不足”。在确定性、已知初态/材料/完整加载下，精确物理积分本来可能恢复全部状态，需把信息缺失与有限表示/计算能力分开。
2. **Q2 历史预测收益：**一个主要读数为等family、等跨度的未来几何增量MAE改善 `L(C)-L(H)`。误差容差由独立开发侧的数值收敛、观测重复性和实际可分辨增量确定，不能沿用8.11%或任意10%。D/R用于归因解释，不用来事后投票救主指标。

不能凭小范围邻近扰动宣布严格全局误差上界；将其称为已检验敏感性范围，并报告随匹配容差收紧和网格/步长变化是否稳定。没有足够参考精度时，结果是未能区分，而不是隐藏状态不存在。

同parent的所有预历史、窗口、两个跨度、restart、重网格和噪声副本必须位于同一划分。12family可作预定整family交叉验证的探索比较；不产生真实试样统计推断。要声称未见历史模板迁移，须整模板留出；只有两个模板时不能通过调参后测试同模板冒充迁移。

报告所有family的当前匹配距离、隐藏状态差、未来轨迹/增量、C/H误差；同坐标/同色标展示观测和状态，包含失败例。相同初始观测随后不补观测的预测，与逐步重置/同化分开报告。

## 6. 真实验证 R：把synthetic结论连接到物理目标

PHM是当前“已知加载＋独立模态裂长”最完整的补证候选，适合检查跨试样响应历史信息，但当前稀疏原生时点未形成足够固定跨度对照。SCB最接近沥青材料，但原始包尚未取得。二者不能混成一个数据集，也不要求每种模态都必须是DIC。

主问题为在实体/加载/几何条件明确后，H是否改善未见试样的独立裂长增量；沿原SCB/B owner已有协议处理，不覆盖原UQ的A/B/C或CRPS问题。所有筛选只用过去，未来载荷仅使用起点已知计划。未来光学标签不得通过跨未来插值“补密”。物理匹配容差先由参考重复性与采样精度确定。

同状态重采用于测量变化；不同实体用于泛化重复；相邻时刻两者都不能自动替代。对新受控加载路径试验，应记录到共同续载后的短/中跨度、同相位测量及独立参考；若材料/初裂纹并非完全匹配，以分层/随机分配和重复估计其变异，不把试样差异全算历史效应。

## 7. 运行成本：合成数据不是免费的

本轮0新FEM/0fit/0GPU。现成大网格约86,408 Q4单元；当前owner设计600子步每轨迹上限20 hosth、每子步120秒，实际完整平均速度未证。已保存第一步34.2491秒包含IO/特征，不能外推为全轨迹均速。

给出可数工作量，供下一次一次性任务授权使用：12family×2history×(最多600前史子步＋100共同未来子步)=**最多16,800个接受子步**；两个跨度从同一未来轨迹读取，不重复求解。仅按120秒子步上限相加为560 hosth，尚不含额外资格/失败/IO成本，也不是完成时间预测；每步若新增两项GP float64证据，仅这些字段就约86.5GiB，完整状态远大于此。因此**不建议直接在当前大网格铺开此库**。

可选执行路径：

- 先把已有600态用于观测接口开发。首个有希望的c1/c11已被完整场核查收紧；不将它当现成严格对照。进一步按实际观测精度搜索可复用原档，但不能无限搜索或绕过原数值资格；不增加producer运行。
- 如果要自建主挑战集，选择为该信息问题设计的较小2-D试件/网格，沿用明确的疲劳模型和严格接受语义。网格/步长收敛、疲劳活跃及可达匹配是必须解决的具体阻塞，不能默认小网格已有效。
- 给下一次任务的**候选资源上限**可设24 hosth、0GPU、50GiB总存储，其中2 hosth用于必要数值/成本核查；若坚持16,800步，剩余预算要求均步耗时≤4.71秒。这是预算反推的可行条件，**不是测得性能或已有授权**。做不到则先选择更少的预定family/更短有效跨度或新的额度；不能边看结果边删失败组，不能将未完成库写成方法负结果。
- 若只问Q1的机制存在性，可预先缩窄到少量family，保持全部数值/观测对照，明确不作学习泛化结论。是否缩窄须在看未来结果之前决定。

本轮不提供可直接启动的producer卡：实际小网格、日程、接受态审阅和总预算还未核定。用户本次授权是核查与方案整理，不继承原A/B的运行额度或失败重试机会。

## 8. 不同结果怎样真正改变路线

| 结果 | 下一决定 |
|---|---|
| 完整状态native重现也失败 | 修复状态/数值转移合同；不能讨论观测历史收益 |
| native重现正确，但有限模型O不行 | 近似器/表示能力问题；不归因于信息不可见 |
| 当前观测难分而未来可分，有限H仍不能区分 | 该历史表示/模型预算未恢复信息；先分辨表示/估计限制。只有完整允许历史观测在既定精度下也不可区分而未来可分，才支持该观测通道不可辨识，考虑增加反力/探测加载/传感 |
| 加入已知加载历史后H优势消失 | 用可测驱动和简单状态，停止扩大响应记忆模型 |
| H只在带噪数据有效，R同样有效 | 主要是降噪/观测估计收益，不称隐藏损伤记忆 |
| H超过C且替换自身对应后优势减弱，跨family稳定 | 支持该合成生成器和观测协议下的历史状态组件；再做真实独立目标验证 |
| 仅同生成器/同历史模板成立 | 保留synthetic表示成果，不宣称模型外或道路迁移 |
| 真实独立试样也有超出参考歧义的未来增量收益 | 推进物理状态估计与预测；再评价物理先验的额外价值 |
| 始终找不到合法共同支持/可达配对 | 放弃严格matched-pair解释，改为条件预测或重新设计测量/加载，不强凑数据 |
