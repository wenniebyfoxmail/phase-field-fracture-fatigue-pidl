## 必须修正

### 1. Q1 的输入集合与 Q2 强基线不同，必须明示

- 位置：主协议 §1 Q1、§5.1–5.2、§5.4 第1项（约131行）、§8。
- 问题：配对匹配的是当前几何/响应与当前/未来加载；两臂的过去加载故意不同。然而 C 按 §5.2 已拥有完整已知过去加载及暴露量。这样的配对可以支持“当前观测单独不是充分状态”，不能直接证明“C 的全部允许输入仍遗漏可预测信息”。在固定确定性模型/已知参数/初始化下，完整加载前缀可能已决定全部状态，H 的任何有限模型收益也可能只是帮助近似求解该映射。
- 最小修正：明示 Q1 的信息集 `I0={当前几何/响应、材料/边界、当前相位、未来计划}`；Q2 的强基线 `IC=I0+已知过去加载/年龄`，候选 `IH=IC+响应历史`。Q1 的配对结论只针对 I0。如果要讨论 IC 非充分，必须另证 IC 也在其可辨精度内匹配，或者承认其问题变成有限模型表示/估计效率。不能将 Q1 成功自动当成 Q2 有望成功的证据。

### 2. 有限 H 失败不能推出历史通道不可恢复

- 位置：主协议 §8 约169行：“当前观测难分而未来可分，H仍不能区分”→“当前信息不足，但现有历史通道不可恢复”。
- 问题：单一编码器、有限ridge/小型模型与有限family的阴性，不证明历史观测中没有信息；即使 learned O 通过，也不能据此证明 H 代表的观测到状态逆映射可由同一简单模型充分表达。当前文字把“本方法未恢复”和“物理/统计不可辨识”合并。
- 最小修正：改为“Q1仅在其指定精度下得到支持；本次历史表示/有限预测族与预算未恢复收益，暂不扩大同类模型”。只有在完整允许历史与其误差集合也无法区分、而未来明显可分，或有独立识别性证据时，才可称该历史通道不可辨识；否则增加传感、改表示或停止均为待比较的路线，不是已经被证明的必要结论。

### 3. 将已承诺的 null 实例化，并保持过去驱动先于 H

- 位置：主协议 §5.3–5.4；真实审计约108行。
- 问题A：完整状态 null 的理论含义已解释正确，但比较表只有 O，没有明确 `O+H`。native restart是状态保存/转移检查，不是有限预测器对冗余历史的阴性对照。
- 最小修正A：只在无噪声 null 分支增加 `O` vs `O+H`、相同预算的有限模型对照，native restart仍独立记录。若冗余 H 改善 learned O，标作有限近似/正则/选择效应，不能当新物理信息；不要求该效应数值严格为零，也不把它机械扩成全部因子网格。
- 问题B：真实审计写“几何+当前+future drive；再加past response；再加past drive”，会使中间 H 增益混入已知驱动的缺失。
- 最小修正B：同步为 C 已含全部起点已知的过去/未来驱动和暴露量，主比较再加响应历史；删去/压缩过去加载仅作为另列诊断，不能代替主基线。

### 4. Mendeley 的独立裂长覆盖须无歧义

- 位置：真实审计约24行“17组没有独立裂长标签”。
- 问题：本审计同时说明四sheet只覆盖两个编码且裂长来自同DIC/PT链。“17组没有独立标签”容易误读为另两组具有独立标签，与约26行及主表不一致。
- 最小修正：写为“已查发布裂长表只覆盖两个编码、156行，且属于同DIC/PT链；其余17发布组连这种已查裂长表覆盖也没有。本轮19组均未核实独立光学裂长参考。”保留公开表头 Ground Truth 为原作者标签名，不升级为本项目独立真值。
