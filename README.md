# Phase-field fracture with PIDL

Shared code and runnable configuration for the phase-field/PIDL research
workspace.

## Start here

`AGENTS.md` -> current HQ / Experiment owner card ->
`research-decision-core` bootstrap for a route choice -> only the operator
document required by the task.

The active research structure is **HQ -> Experiment -> Run -> Evidence**.
Historical frontier, ledger, and handover documents are references, not default
entry points.

## Repository map

- `source/` — reusable implementation
- `SENS_tensile/` — tensile PIDL cases, runners, and fixed benchmarks
- `docs/` — concise current maps plus on-demand operating/history references

Generated outputs and raw artefacts are kept outside Git and linked through
their Run ID, commit, and stored path.
